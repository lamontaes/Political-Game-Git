# Story check

**Look first:** run the `look-first` search before checking, filing or asking.

A line is checked three ways, in this order. Each part is a whole skill kept as it was, so every owner quote and rule is in it.

| Check                                                                                                                                                                                                           | Read                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| The scene standard: a scene exists only if it writes something back, roles are cast from the world, lines vary by the speaker's traits, narration never restates the screen; and a scene builder's first report | `references/scene-standard.md`   |
| The pre-grade: a session that did not write the lines plays fresh lives and grades each line the way the owner does, calibrated on his real verdicts                                                            | `references/pre-grade.md`        |
| The words stamp: how a words reader reads a pull request's player-visible words, and what a builder sends to get that read                                                                                      | `references/words-stamp-read.md` |

Nothing waits on the owner's grading (his Nov 24 rule: a batch counts after the sameness gate and the pre-grade, and plays right at three drawn places).
