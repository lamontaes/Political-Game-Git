# The separate core chooses acts and limits routine history

The prototype evaluates needs, goals, drives, traits, and emotion, then chooses available acts with shared consequences. The player follows those same rules. The current focused checks passed 141 tests across eight files. Annual performance and the five-year pre-run remain unmeasured. The playable game does not import this folder.

Before: the matched old-core busy day measured 2.14 simulated days per minute. Weekly retirement removed 134,000 outsider records, and that run measured 1.08 days per minute. These receipts do not establish annual speed.

After: the prototype has mutable ID tables and indexes, actor-specific knowledge, generated households and jobs, summarized past facts, real public institutions, tier calendars, and the shared life loop. Open assumptions remain registered and block prototype release.

## What is checked

The [life loop](life.ts#L292) advances real calendar days. Its [chooser](life.ts#L163) uses existing trait data and records need, goal, and drive contributions. The current state, emotion, calendar, and tripwire gate passed 103 tests. The life, civic input, population, and deep-past gate passed 38 tests.

The [state API](state.ts#L300) validates mutations and knowledge access. Payments conserve money. Memberships record requests; organizing records a plan; approaching recorded staff opens a callback. These outcomes do not establish permission, admission, or a passed law. The [civic importer](civic-inputs.ts#L107) uses actual directory identities and recorded workers.

The current API and schema are versioned. Content registries and module operations are open to data extensions. A checked extension adds a need, goal, trait, and act through data using the existing module. Routine outsiders retain results and short reasons; full traces remain for the player, supplied focus people, or observer mode.

## What still blocks acceptance

One discretionary act per activation is not a complete daily schedule. Household consumption, hiring, employer revenue, births, deaths, elections, and law effects are missing. The event-chain check supplies its initial event; a generated-world event producer remains pending. Missing January 2021 laws and offices, inherited authored job choices, and incomplete deep histories have registered gaps.

Guessed parameters are tunable. Unsupported citations were removed. Empirical bounds for utility weights, effects, and half-lives remain unmeasured, and their guard remains red. PANAS/PSS scores and ATUS activity durations are observable targets with different units; they do not establish these coefficient bounds.

There are 38 open stopgaps. The [release gate](stopgaps.ts#L39) refuses them. The full year, memory receipt, self-started act totals, generated causal chain, mood and stress samples, five-year pre-run, and P9 life receipt remain in progress.

## Method

All execution stays in the cloud. The [old-core baseline receipt](receipts/old-core-baseline.json) preserves the measured warm samples and original receipt hashes. Measurements will use one frozen opening input and three warm runs. No new old-core world run was made.
