# Data tables

Four JSON tables the game reads directly. Each keeps the export names of the
generated module it was first taken from as its top-level keys; compact row
strings, metadata, nulls and missing-field conventions are kept as published.

| Table                        | Read by                                   | Source and vintage                                                                                                                                                                                                                                                                                  | Regenerated by                                                                                                                  |
| ---------------------------- | ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `place-population.json`      | `src/core2/gov-rules/place-population.ts` | [Census Vintage 2025 subcounty population estimates](https://www2.census.gov/programs-surveys/popest/datasets/2020-2025/cities/totals/sub-est2025.csv), July 1, 2025. Verified input: `docs/research/chatgpt-answers/2026-09-23-cto-handoff-2230/DATA-Census-Vintage-2025-places-50-states-DC.csv`. | `npm run compile:place-population` (`-- --check` fails on a stale table)                                                        |
| `local-business-counts.json` | `src/core2/modules/credit.ts`             | Census County Business Patterns 2023 (NAICS 2022 four-digit establishments and employment), Economic Census 2022 (sales and employees), and BEA CAINC1 line 2 population for 2024.                                                                                                                  | None in the repository; a snapshot.                                                                                             |
| `town-deposits.json`         | `src/core2/modules/credit.ts`             | [FDIC Summary of Deposits](https://api.fdic.gov/banks/sod?filters=YEAR:2026), June 30, 2026, read September 29, 2026. County branch deposits in thousands of dollars; preserves the exclusion of main offices of banks with assets over $10 billion.                                                | `python3 scripts/research/compile-fdic-county-deposits.py <folder>`, run from the repository root on the API's JSON pages.      |
| `town-bank-shapes.json`      | Nothing in the game yet.                  | [FDIC BankFind financial call reports](https://banks.data.fdic.gov/api/financials), June 30, 2026, for institutions with assets under $1 billion. All 3,194 ratio rows retained.                                                                                                                    | `python3 scripts/research/compile-fdic-town-banks.py <folder>`, run from the repository root on the three call-report extracts. |

## Value conventions

Do not reinterpret these tables when reading them. Population rows keep the
four published zero estimates. Business rows keep their original zero
conventions, including withheld sales. Bank ratios, record order and deposit
units are unchanged.
