# P2R2 — the callback surface, row by row

Forty-one rows: thirty-three family return summaries, the last-resort generic,
and the seven strings the callback handler writes when a scheduled return comes
to nothing. Every one was read. Every one changed, and the reason each changed
is its own.

## What was wrong with the surface as a whole

Two measurements from the P2A2 review, reproduced against the PR head before
anything was edited:

- Twenty of the thirty-three family rows opened `Your decision about`.
- Thirty-one of the thirty-three closed on one of three near-identical frames:
  `came up again`, `came back up`, `came back around`.

That is one sentence with the nouns swapped, applied to a family asking for two
weeks, a debt, a colleague in trouble and an approach about running for office.
It is grounded and it is bad, which is the distinction the owner rules exist to
draw. A near-duplicate cluster of six rows in the bounded scope metrics was the
same failure showing up as a number.

Three rules were applied, and they are visible in the module's own comment:

1. **Name the thing, not the decision about the thing.** A callback returns the
   subject, not the player's earlier state of mind about it.
2. **Say what the handler has established, and stop.** By the time one of these
   is written the handler has confirmed the counterpart is still connected and
   that they chose to raise it. That is a fact. What was said, how it went and
   what it cost are not, and none of these claims them.
3. **Do not converge.** The first draft of this repair replaced one frame with
   another: four rows ended `put to you once more` and thirteen ended `with you
again`. Both were measured and both were broken up. Neither is a defect the
   original review named; they were found by re-measuring the repair.

## The generic

`GENERIC_RETURN` is now _Something from a while back came up again._ It is the
last resort for an origin whose tag no summary covers, a test holds that every
schedulable family has its own sentence, and so it stays unreachable in ordinary
play. It was `An earlier choice came back up.` — the frame every other row was
also using, which is what made the frame invisible.

## The seven handler strings

These are the `context` recorded on a future-due-item state when a scheduled
return is blocked or cancelled. The P2A2 review found database diagnostics
sitting in a player-facing prose surface. No player surface reads this field —
that was checked — so the repair is to write them as what they are.

| Was                                                                                          | Now                                                                                                   | Why                                                                                                                                                                                                            |
| -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The person or earlier event is missing from the record.                                      | Diagnostic: the subject person or the originating event is absent from history.                       | A broken reference is not something that happened to anybody. Third person, prefixed, addressed to whoever is reading an audit.                                                                                |
| Your record is missing, or it records your death.                                            | Diagnostic: the subject person record is absent, or a death is recorded for them.                     | Second person made a schema failure read as narration about the player's own death.                                                                                                                            |
| The other person’s record is missing.                                                        | Diagnostic: the counterpart person record is absent.                                                  | Same class, same treatment.                                                                                                                                                                                    |
| The household, kinship, work or group connection needed for this follow-up is not on record. | Diagnostic: no household, kinship, employer or organization link between the two people is on record. | Named the actual record families so the diagnostic is usable, and dropped the "needed for this follow-up" framing that read like an explanation to a player.                                                   |
| There is no active commitment to follow up on.                                               | Diagnostic: no active life commitment remains for this follow-up.                                     | Named the record type.                                                                                                                                                                                         |
| It was still there to be raised, and the person who could have raised it did not.            | _unchanged_                                                                                           | Not a diagnostic. Somebody had the chance to raise it and did not, which is a decision they made rather than a row that is missing. It is the one string here that describes the world, and it stays as it is. |
| An earlier choice became relevant again.                                                     | An earlier choice was raised again by somebody who was there.                                         | The resolved case. "Became relevant" is a system word for a thing a person did; the handler has just established who did it.                                                                                   |
