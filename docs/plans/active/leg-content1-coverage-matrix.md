  per-transaction charges remain distinct. No annual cap is compared with a
  whole-program appropriation; mixed periods are not summed. New annual
  provision metadata is optional, validated and saved through existing writers.
- Changed appropriation, eligibility, sunset and workforce families use v2;
  old records retain their text/identity. A mismatched family version refuses
  recompilation and does not borrow the current bank's instrument/limits.

  baselines and an effect model. The separate explicit **conditional spending
  scenario** uses existing `government.outlays`, a proposal-specific zero
  incremental counterfactual, a selected interval and disclosed full-funding/
  administration/spending assumptions. It is an actual policy estimate with
  private actor knowledge, not a measured government budget or service forecast.
- Normal life worlds currently lack the required production catalogs: their
  explicit request refuses without creating an estimate. Successful recording
  is verified against the existing catalog-backed legislative fixture.
- Alternative, baseline, operation, implementation profile, projection root,
  estimate and knowledge all use accepted writers. Exact measure/provision IDs
  are preserved in a private request event. No metric, resource, realization or
  effect activation changes. Stale scope/version/frontier requests refuse.

## LEARN

A missing measurement is a reason to withhold a forecast, not an authored
prospective clause. A record's label must not select its mechanics: revenue uses
the instrument; annual amounts carry typed period metadata; existing-versus-
proposed authority comes from canonical stage. The new boundary regressions
encode these recurring errors instead of adding more launcher instructions.
