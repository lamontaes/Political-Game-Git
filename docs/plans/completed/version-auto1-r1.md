## LEARN pass

The recurring controls belong in small executable seams, not operator prompts:

- tests inventory the privileged publisher and forbid checkout, Node, npm, dependency, and repository-script execution there;
- candidate identity is a commit/tree/parent tuple created before validation and digest-bound across the job boundary;
- rollout history is authoritative only when read from the comparison base, so a branch cannot rewrite its own exemption;
- multi-file local writes require a durable transaction decision and recovery direction, not merely per-file atomic renames.

These lessons are encoded in `docs/release/README.md`, the workflow structure, and focused adversarial tests.
