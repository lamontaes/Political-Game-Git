## Runtime selection contract

`openingRegionTypesForPlace` matches canonical locality scope, exact GEOID, full display name and state jurisdiction key. The first batch adds only the ten rows above. A changed name/state, unknown place, county record, or another municipality receives no new type. Existing 57 associations remain intact. No nearest-place, shared-county, majority-area, state-name or adjacency fallback is added.

`selectOpeningRegionalPlate` receives those types through the existing opening scene context. A candidate explicitly covering the matching type is eligible subject to its own season constraints. The selector still prefers exact-place coverage and deterministically resolves equal specificity. A regional mapping does not add a candidate to the production bank or bypass approval. If no approved compatible candidate exists, the existing fallback remains.

Expected contrasts: Lubbock selects a southern-high-plains candidate, Alpine selects trans-pecos-desert-mountain, Nacogdoches selects southern-pine-hardwood, Ely selects northwoods-lake-forest, Luverne selects upper-midwest-tallgrass-prairie, Stowe selects green-mountain-forest and Burlington selects champlain-lake-lowland. Boise City shares only the explicitly matching High Plains type; Sulphur shares only Cross Timbers. This does not claim western Texas resembles eastern Oklahoma generally.

Explicit negatives in this batch: Amarillo, Wichita Falls, Broken Bow, Hugo, Grand Marais, Winona, Middlebury and Newport remain unclassified by these new types. Some may support future associations; their absence is bounded coverage, not evidence that their landscapes are incompatible. New matching evidence and independent asset review are needed before expansion.
