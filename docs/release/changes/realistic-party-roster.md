title: Who holds each seat at the start follows each world's own vote
---

Each new world opens with its own holders in Congress, the governorships and the state legislatures. A seat changes party only where that world's 2024 vote carries the seat's own result across even against the party that holds it, so close seats differ from world to world and safe seats stay put. Chamber majorities, the Senate that confirms a president's nominees, each state's parties and the races outside the town all read the world's roster.
