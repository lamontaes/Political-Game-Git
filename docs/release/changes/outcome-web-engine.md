The game now has one shared table for how one area's conditions move
another's, such as unemployment and health coverage, or health coverage and
medical bills. Each link has a direction, a size, a shape and a delay before
it is felt, and the checks refuse a link that moves itself, repeats a law's
own direct effect, or loops back in the same month. Links the research found
to have no real effect, such as work rules on employment, are carried as zero
on purpose. The crime rules' unemployment effect now runs through this table,
unchanged. Nothing else reads the table yet.
