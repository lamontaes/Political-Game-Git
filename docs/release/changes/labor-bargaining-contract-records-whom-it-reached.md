id: labor-bargaining-contract-records-whom-it-reached
impact: none
section: Changed
title: A public unit's bargaining contract now records each worker it raised.
---

When a public unit's contract settles, the law's reach names every worker the raise landed on (a named worker by person, a counted employer's workers as one group), so the law's page and the wiring check can follow it to a paycheck. Pay and dates are unchanged.
