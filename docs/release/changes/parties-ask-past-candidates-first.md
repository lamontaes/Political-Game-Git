title: Parties ask their past candidates first, and early filing deadlines are kept
---

When a seat in Congress or a state legislature comes up again, each party
first asks the person it asked in that district last time, who decides again
for themselves. The game makes up a new person only when nobody from before
can run, so a long game no longer piles up unused candidates: a watched game
in East Middlebury, Vermont, held 2,982 people by December 2030 instead of
4,062.

A state whose real filing deadline falls before the game opens, such as
Texas on December 8, 2025, now starts with its candidates already filed on
that day, and later cycles file in the year before the election as the real
calendar does.
