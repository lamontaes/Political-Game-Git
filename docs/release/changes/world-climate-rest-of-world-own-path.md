title: The rest of the world's CO2 follows each world's own trend, not a real published path
---

Every world's rest-of-world emissions used to follow the same published scenario line, so two worlds with the same laws warmed identically. Each world now draws its own steady trend when it opens, and its warming and hazard levels follow from it.
