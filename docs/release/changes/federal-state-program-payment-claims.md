id: federal-state-program-payment-claims
impact: patch
section: Changed
title: Federal programs settle admitted state payment claims through existing public accounts
---

Saved federal appropriations can carry dated state payment claims referencing
an exact final adopted amount or matching ratio. Matching claims reference actual
posted state program expenditures. The existing public-program commitment and
installment writer checks available authority and cash, posts the federal debit
and state credit, and retains claim provenance and replay protection. The monthly
budget handler admits due claims after closing the preceding month, preserving
the actual posting month. This adds no default claims, legal rates, allocations,
or estimated cash for programs whose payable source inputs are absent.
