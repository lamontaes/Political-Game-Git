The first-month-friend and couples tests now expect a grown-up start to hold a
job, so the people at work are offered on day one and the walking group is
picked on purpose. The guardian test rebuilds its guardian-only case now that
a generated start records the guardian's kinship. The thirty-day friend test
gets a limit sized to its measured seventeen minutes, and a day profile is
added. Nothing a player sees changes.
