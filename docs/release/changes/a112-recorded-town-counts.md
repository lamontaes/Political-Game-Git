---
id: a112-recorded-town-counts
impact: minor
---

Town counts use the recorded place turnout and saved candidate support. They no longer draw these count inputs or create a minimum number of ballots. A missing turnout, zero ballots, or an unresolved winning or advancing tie leaves the contest pending without assigning a winner by filing order. The local count blocks the shared contest fallback so that a refusal cannot become a fabricated result later in the same queue. The remaining filing and calendar estimates are unchanged.
