title: Towns with many homeless households play faster
---

Each month the game checks whether households without a home can rent again. For each household, it used to rebuild the whole town's homes and jobs just to find the typical rent. Now it reads the rents alone, once, until something changes. Storrs, Connecticut's first year runs about 17% faster. Nothing in the world plays differently.
