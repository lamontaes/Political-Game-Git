impact: patch
section: Fixed
title: A saved life whose state voted on a constitutional amendment opens again after the legislature sizes were corrected.
---

Correcting the sizes of Nebraska's and New Hampshire's legislatures made every saved life that held an earlier amendment vote in those states fail to open with "That saved game could not be opened." A vote already taken is now checked against the chamber that voted, and new votes still use today's sizes. When a large save is not read on the first try, the game tries again twice before it reports a problem. If a save still cannot be opened, the game now says it has been kept, not deleted.
