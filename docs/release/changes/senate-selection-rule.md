title: How senators are chosen is now a rule an amendment can change
---

Each state's U.S. senators are elected by its voters, as the Seventeenth
Amendment requires, and that is now a rule the game reads rather than an
assumption. An amendment to the U.S. Constitution can return the choice to
the state legislatures, as before 1913. Then no one files with the voters
for a Senate seat: at the regular election each legislature's majority
chooses the senator, and an empty seat is filled by the legislature on the
second Tuesday after the vacancy, as the 1866 federal law had it. No state
bill can change the rule.
