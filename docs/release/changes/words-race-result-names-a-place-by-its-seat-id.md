title: A race result never names a place by its record key
---

When someone tells you how a state legislative race went, they no longer say a district's record key as if it were a place ("seat:US-VT:lower:L-2:0 gave Carlos Gibson the most"). The place that gave the winner the most is named only when the race was counted over more than one place with real names.
