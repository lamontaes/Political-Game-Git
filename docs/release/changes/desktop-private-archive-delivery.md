summary: Deliver the install-once private Mac ZIP separately from plain game artifacts.
---

The private Mac artifact contains only the symlink/mode-preserving controller
archive and exact compiled checksum/profile receipt. Unpacked `.app` directories
are not offered as installable artifact-service transfers. No runtime, save
codec, updater/controller, version number or public-release behavior changes.
