title: Dev mode shows the director's board for a day, and a forced scene says what the board did with it
---

In dev mode's scene trace, a board section shows every scene the director weighed on a day, the reason each one was cut or the score it was felt at, which one it picked, and how much room the life had left. Forcing a scene now says whether the board staged it or which gate held it back.
