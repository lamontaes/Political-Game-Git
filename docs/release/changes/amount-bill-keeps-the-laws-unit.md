id: amount-bill-keeps-the-laws-unit
impact: patch
section: Fixed
title: A law passed in dev mode keeps the law's own unit, such as dollars a month, instead of a percent.
---

A bill that changes an amount, such as SSI's monthly benefit, now enacts the new amount in the same unit as the law it changes. Before, a bill filed from dev mode recorded it as a percent.
