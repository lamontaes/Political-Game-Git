title: Who may run for the legislature follows laws passed in the game
---

When a law passed in the game changes the minimum age for a legislative seat,
or how long a candidate must have lived in the state or district, running for
that seat now follows the new rule from the day the law takes effect. The
reason a character cannot run names the law. A law can also remove a residence
period entirely.
