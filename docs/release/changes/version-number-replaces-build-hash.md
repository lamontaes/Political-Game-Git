id: version-number-replaces-build-hash
impact: patch
section: Changed
title: The corner shows the version number instead of a build code
---

The title screen and every play screen now show the release version, such as v0.5.0, in the bottom-right corner in place of a seven-character build code. The desktop hub names the version beside the game you are playing, and its Install update button no longer shows a build code.
