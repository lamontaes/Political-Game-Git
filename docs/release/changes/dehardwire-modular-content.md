section: Fixed
title: The game stops describing everywhere as if it were one town
---

Several screens had a single place, state or school year written into them, so they described the rest of the country with the wrong details or refused to describe it at all. The economic panel now names each figure's own geography as the source names it, instead of saying Fayette County and Lexington-Fayette wherever you live. An ethics complaint is routed by the state it belongs to rather than by the word "Kentucky" appearing in a name, so a complaint filed anywhere reaches the right body, or honestly says nobody has recorded one. The school directory can read any published year, not only the two that were written in. Conversation subjects and the municipal screen ask the records instead of a fixed list.

Underneath, a state's identity now answers the same way whichever path created it, and each state's candidacy rules cite the constitution they were actually read from and the date that text was seen — so no state's requirements can be published under another state's source. Where a rule has not been read, the game still refuses to let someone file rather than waving them through.
