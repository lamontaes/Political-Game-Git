title: A work law reaches workers the day it takes effect
---

The jobs engine's day cache for the outcome web now refreshes when the web writes a new month, so a law that takes effect partway through a day (such as a town's partnership with federal immigration enforcement) reaches workers' pull to work that same day instead of reading the old answer until the next one.
