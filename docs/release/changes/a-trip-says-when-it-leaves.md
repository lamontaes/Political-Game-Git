title: A trip says when it leaves and how long it takes
---

In Elko, Noah's 15-minute trip to a friend's house on Saturday read "6090
minutes, including any wait before it begins," and in Lewiston a county party
meeting read "1980 minutes." The number was every minute until the activity
was over, starting from now, and it looked like a trip lasting days. Each row
now says when the activity starts and how long it takes, for example "Starts
Saturday, January 10, 2026 at 2:45 p.m. and takes 15 minutes." Where the
visit includes a trip, the row also says how long the trip there takes.
