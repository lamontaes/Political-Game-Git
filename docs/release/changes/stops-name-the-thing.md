section: Changed
title: A stop says what stopped the clock
---

When the day or week stops early, the notice names the thing itself: "Stopped
before Tuesday, January 6, 2026, 7:00 AM. Journey to the public meeting comes
first." It no longer says it stopped "for something protected that needs you".
The note under each skip reads "Stops early if anything needs you first."
