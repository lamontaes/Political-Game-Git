title: An election has a field, not a single rival
---

Every race in the game drew exactly one opponent — the same in a Chicago House
seat and a Galena one, for every office and every state — so election night was
always two names and the winner usually took seventy to ninety per cent of the
vote. A contest now opens with two to four people standing against you, and the
field is fixed for a given save, so reloading does not reshuffle the ballot.
Winning shares came down to roughly half in the towns this was walked in.

This is a realistic range rather than a claim about real American fields; how
many challengers a given seat actually draws is still an open question.
