A new check lists every policy question, state, federal and local, that no
sized path lets act on money, people or places. The 49 questions without one on
September 29, 2026 are its starting list, and the list can only shrink:
`npm run unwired-laws` prints it by category, and `-- --update` removes a
question once it is wired. Nothing changes for a player.
