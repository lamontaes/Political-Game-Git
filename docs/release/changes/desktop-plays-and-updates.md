---
id: desktop-plays-and-updates
section: Added
title: The desktop app updates itself from Check for Updates
impact: minor
---

Every release is now published with Mac and Windows installers. In the installed app, Check for Updates finds a newer release, downloads it when you say so, and installs it when you choose (on a Mac, when you quit, the new version replaces the old one in the same folder and opens). The window title shows the version and the commit it was built from.
