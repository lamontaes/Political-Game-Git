title: See your own character on the main menu

Returning to the main menu with a saved life now shows that person standing at the lectern in the community hall, composed from their own appearance, instead of an empty room. The menu falls back to the room on its own when a build carries no lectern illustration, so nothing is missing where the art is not installed.
