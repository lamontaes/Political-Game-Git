id: elections-one-seat-per-body
impact: patch
section: Fixed
title: A sitting member of a body can no longer run for a second seat on it.
---

A person never holds two seats on one body. A sitting council or board member may file only for their own seat, for re-election; where a body's seats are elected at large, the seats up on one day are one race, so a member whose seat is in it stands in it. Before, a member serving one seat could file for a different seat of the same body and win it too. The filing counter no longer offers such a race, and the clerk's check refuses it for everyone, officials and the player alike.
