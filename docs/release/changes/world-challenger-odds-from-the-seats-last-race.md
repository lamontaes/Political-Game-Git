title: A challenger's chance against a sitting holder follows how narrowly the seat was last won
---

People weighing a run against a holder used to read the same small chance at every seat. The chance now follows how far ahead the holder finished in the seat's last race, so a narrowly held seat draws challengers and a safe one does not.
