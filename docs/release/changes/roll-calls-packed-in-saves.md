section: Fixed
title: Saves with years of Congress votes are much smaller.
---

Every recorded vote used to write each member's seat, name and reason in full, so after twenty game years the votes of Congress were a third of a save. A save now lists each set of members once and writes every vote as a short code against it. On the 61 MB Ketchikan save that is 43 MB, and the world it loads is identical. Saves written before this still open, and each is rewritten in the smaller form the next time it is saved.
