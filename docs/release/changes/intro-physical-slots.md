title: Intro casts use recorded roles and measured scene slots
---

Intro casts shown on registered place backgrounds now use the ordinary measured
scene-layer reader. Selected people retain their actual slot, pose, facing,
depth, source recipe and recorded role provenance. State representatives retain
the existing district-qualified roster and canonical work record. Family
illustrations retain kinship or child-authority records without claiming room
attendance. Intro staging never adds scheduled workers.

Candidate plates without their own measured staging contract keep an explicit
physical-placement gap. This change preserves every source raster and requires
same-place screenshots and owner review before scene integration.
