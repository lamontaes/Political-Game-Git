title: Some people were arrested before the game began

A person's past can now hold an arrest before they turned 23, and for some a felony conviction and a prison term served before the game began, in the shares real Americans have them. A prison term ends their job or their search for work, which starts again on release. The card and the Journal tell all of it with the lines already written for the law.
