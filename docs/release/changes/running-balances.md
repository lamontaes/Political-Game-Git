id: running-balances
impact: patch
section: Improved
title: Paychecks stay quick as a worker's years add up
---

Withholding a paycheck's taxes checks what the worker holds, and so does
recording the payment. Each check added up every payment the worker had ever
made or received, so every paycheck cost a little more than the one before.
Each account now keeps running totals as payments are recorded, and a balance
is read from them. A balance at an earlier moment, or for an account opened
after some of its payments, is still added up payment by payment. Every
balance comes out the same.
