title: Minimum wage and teacher pay floors stay quick on paydays
---

On each payday, the minimum wage and the teacher salary floor check which
jobs have ended and when each job was last paid. Each check read every job
status and every paycheck the world had ever recorded. Both now read indexes
that grow with those records, and the check for legislative seats recorded
before terms were dated reads only legislative seats. In South Fork,
Pennsylvania, each of the first ten game years runs 0.2 to 2.3 seconds
faster, and the world after each year is exactly the same as before.
