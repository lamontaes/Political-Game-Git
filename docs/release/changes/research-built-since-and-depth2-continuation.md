The research queue can now list everything merged to main since a given
commit, for ChatGPT to review, with `npm run research:request -- built-since
<rev>`. It reads the merge history itself, so a merge nobody announced still
appears. Each entry names the pull request, the files worth reading, and the
research questions the merge touched.

ChatGPT's DEPTH2 continuation is written back too: the completed crosswalk
between its 92 research subjects and our 127 issues, sourced legislative
timing rules for five places, and local income-tax authority, recorded under a
new question because ChatGPT raised it unasked. Two new questions are filed,
on which traits a person carries beyond the five dimensions and, read first,
the rules for mayors. Nothing in a running game reads the queue.
