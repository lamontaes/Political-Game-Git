title: An unfilled opening's pay no longer jumps when nobody is looking for work.
---

An employer raises an unfilled opening only as far as job-seekers ready to apply could be drawn by it, so a cashier opening no longer climbs from about $16 to over $100 an hour in one review while nobody in town is ready to look.
