---
id: back-to-the-counts
impact: patch
section: Fixed
title: People the game stops following go back to the wider population without an error.
---

When you have not dealt with a household for a long while, the game now sends it back to the wider population and keeps every one of its people exactly as they were. A household that cannot go back on a given day, because someone worked that day, simply waits for the next review.
