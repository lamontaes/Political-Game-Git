title: A public pay floor is a law any level can pass
---

A government can now set a yearly pay floor for public jobs as a law. On the day it takes effect, every public job under it is raised, and a monthly review holds later public hires to it. A floor set by a state or the nation also binds the governments under it. Dev mode's $70,000 experiment passes this law.
