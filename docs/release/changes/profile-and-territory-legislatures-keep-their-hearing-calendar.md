title: Profile and territory legislatures keep their hearing calendar
---

A saved state legislature profile remains recognizable when the same state
also has a researched rule pack. Hearing requests in that profile and in a
territory can use the existing shared state-session calendar. An explicit
calendar and a hearing already scheduled keep their supplied dates. The change
does not supply missing executive decisions or admit unregistered rule packs.
