title: Personnel work reads the place's rule instead of a state-name branch
---

Personnel procedures use one jurisdiction table for all 56 places. Unread terms retain a named reference estimate on saved records. Recorded authority, class, tenure and agreement coverage still determine whether an action can proceed. Reviewed economic crosswalks, authored geography identities and amendment thresholds are data rows.
