title: A town's home prices move from the first month, and keep up as months are added
---

A town's home prices, which set its rents, stood still for about a year in a
five-year run in Fayetteville, Arkansas, because the town's own economy began
keeping months only in the second year. The nation's months now carry the
town's prices until then, with no jump at the switch, and a month added to
the world later is always read.
