section: Changed
title: Some residents of a new town have a different first name, drawn by the same rule as everyone else.
---

The town's opening residents now get their first names from the same rule the rest of the opening uses: how often a decade's popular names were given, as measured from Social Security records. Before, part of each town used an older fixed share. Last names, ages, genders and birthdays are unchanged.
