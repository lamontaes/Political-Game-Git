title: Home prices get a measured monthly model, ready for the housing market to use
---

The game now has one place that works out how a town's home prices move in a
month. It follows three things measured across every state from 1980 to 2024:
last year's price change, growth in income per person, and changes in the
30-year mortgage rate, and it pulls prices back when they run far above what
local incomes support. Nothing is drawn. The housing market reads it once it
lands, so home prices change with the town instead of standing still.
