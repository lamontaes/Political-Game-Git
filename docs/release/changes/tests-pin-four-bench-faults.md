Four bench tests that drew their place from a run-time seed now play named places at fixed seeds and stay red there, each with a pool item that says what the player would see: an order with no name, an empty spoken answer, an official's card that does not open with their name, and a job history whose employer is missing.

The amendment test now plays Fulton, Illinois, a town in a state whose law lets towns set a minimum wage, so the ordinance it amends can be drafted; before, most of its draws landed where the draft is rightly blocked.
