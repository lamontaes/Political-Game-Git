title: Territorial legislatures can propose laws
---

A legislature in Guam, the Virgin Islands, American Samoa, the Northern Mariana Islands or Puerto Rico used to be blocked from most proposals as a disputed power. It now has the power a state has on the same question, marked as an estimate until each territory's own law is read.
