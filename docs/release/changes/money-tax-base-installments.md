title: Governments' tax receipts follow the economy's wage bill
---

The named-payer taxes (corporate, excise, customs and the like) are no longer the same every year: each installment moves with the nation's payroll jobs times hourly earnings since the plan's calibration, so receipts rise in a boom and fall in a slump.
