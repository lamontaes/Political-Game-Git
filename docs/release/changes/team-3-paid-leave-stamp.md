# Paid-leave payments carry their governing law

The state paid-leave payment writer now adds the shared law stamp to money actually transferred under an operative program law. Existing payment amounts and state-account funding limits remain in use.

This draft also includes the thirteen-law effect inventory and the first three laws' value-key requirements. No new map sizes or rates are introduced. Changed tests and source checks have not run because the cloud executor is unavailable; runtime proof and complete law records remain pending.
