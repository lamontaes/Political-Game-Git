impact: patch
section: Fixed
title: Show a state's population when a new game starts
---

A new game no longer says "Population unavailable" for your state or map
areas. When the newest figures on file came out after the game's date, the
count for a year that was already public is shown, rounded, as an estimate
("About 7,582,000 people, 2024 estimate"). The voting share on the same card
now reads in plain words: "About 62% of citizen adults said they voted (give
or take 3 points)."
