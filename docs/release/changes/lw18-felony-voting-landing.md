title: A felony sentence now suspends your vote, and the state law decides whether it returns
---

Before, a felony jail sentence never touched a person's vote, so a state's
law on restoring the vote after a sentence had no one it applied to.

Now a jail term over a year suspends the vote while it runs. When the sentence
ends the vote returns where the state's law says so and stays withheld where it
does not, a pardon returns it, and the Journal says which law did it.
