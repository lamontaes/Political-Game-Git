section: Changed
title: Character art cannot reach a person without someone's name behind it
---

Nothing a player sees changes. What changes is what the game will accept.

The rule that banked art and catalog art are different things, and that a
person has to look at art before anyone can wear it, has been settled for some
time. Where that look got written down was settled nowhere, so it was written
down nowhere, and the function that admits a piece of art into the catalog
had never once been called.

Acceptance is now a file that names who looked, when, at what, and which pieces
they accepted. Nothing in the project writes to it, including the tool that
reads it, because a program that can record an approval is a program that can
approve. The catalog is checked against it: every piece of art a person can
be drawn from is either one of the forty-six development fixtures, listed one
by one, or named in an approval. Listing them one by one rather than by batch
is the difference between a rule and the appearance of one — a forty-seventh
fixture appended to the old batch would have walked straight through the
easier version.

The file is empty, which is the truthful state. Nobody has accepted anything
yet.
