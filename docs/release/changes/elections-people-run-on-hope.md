title: Some long shots file for office, and some strong people stay out
---

Whether someone runs now includes their own read of their chances, which for a bold person runs ahead of the real odds against a sitting officeholder. A long shot sometimes files anyway, so a few more races draw a challenger. In Cedar Mills, Minnesota (seed a1) the empty county race that once went to a holdover now has a candidate.
