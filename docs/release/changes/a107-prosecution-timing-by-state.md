impact: patch
section: Changed
title: How long a criminal case takes now follows the state it is tried in
---

Before, every case in every state took the same number of days to reach its plea
or trial. Now eighteen states use the median days from felony filing to
disposition that their courts reported, so the same plea hearing falls on
different days in different states. Every other place uses the average of those
figures.
