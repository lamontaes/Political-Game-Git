An opening scene can now carry later stages, each offered only when the record
holds the choice it answers, with the same person, and enough days have passed
since. Shipped play reads an empty table: which choices come back, and as what,
is filed with ChatGPT as `which-later-answers-an-early-choice-deserves` rather
than invented here, so a player sees nothing new until it is answered.
