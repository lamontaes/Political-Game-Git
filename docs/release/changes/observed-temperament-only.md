id: observed-temperament-only
impact: patch
section: Fixed
title: A person's card no longer names a temperament nobody observed
---

A person's card described how somebody tends to behave — reserved, or
confrontational, or one to think a thing through — before the game had decided
anything of the sort about them. It was reading the number a person is born
with rather than anything the world had written down, so at the start of a life
it would tell you the temperament of four people you had never dealt with.

The card now says nothing about a person's temperament until the game has
actually established it, which happens the first time that person makes a
decision it bears on. Someone the game has established as unremarkable on a
trait still says nothing, because that is a different thing from not knowing.
