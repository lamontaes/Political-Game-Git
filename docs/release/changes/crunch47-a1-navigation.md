title: One Back from a Politics tab returns to the conversation you left
---

Leaving a conversation to look something up in Politics no longer costs two
presses to get back to it. Back from any tab of the hub closes the hub and
returns you to the room with the same line still waiting, and Return to
conversation keeps whatever you were reading before underneath, so the next
Back goes where it always did.
