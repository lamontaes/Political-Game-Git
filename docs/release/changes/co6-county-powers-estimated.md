id: co6-county-powers-estimated
impact: minor
section: Fixed
title: A county's powers are no longer left blank
---

Before, the powers table left 52 county powers unknown, so a county could
debate things no county can decide, and nobody could tell what a county was
allowed to do.

Now each county power is set from how county government works. State or
federal matters such as marriage, abortion and court size are closed to a
county, powers like zoning and policing are limited, and powers a state's
home rule decides still follow that state's law. Counties no longer get a
payroll-tax question.
