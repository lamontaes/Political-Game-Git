When the President signs or vetoes a bill from Congress, the news now says
which President it was, for example "President Brianna Savage signed H.R.
12." It used to read "The President signed H.R. 12."

The members the game seats in the home state's legislature were never shown.
Represented by, under Government, said no one held the player's state House
and state Senate seats, and the State screen said no member of either chamber
was on record. Represented by now names the member for the home's own
district, and each chamber on the State screen lists its sitting members in
seat order.
