Development documentation only; nothing in the game changes.

The research queue's publishing instructions told the renderer to trash the previous Drive document on every refresh. That destroyed any comment left on it and broke any pointer at it, and a trash through this connector cannot be undone by any session. The instructions now say to rename the previous render with a SUPERSEDED prefix and move it to a sibling archive folder, which keeps the document id and everything attached to it.
