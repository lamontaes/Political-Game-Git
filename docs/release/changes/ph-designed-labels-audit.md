title: Game schedules with no real source are marked as designed
---

Before, the council ordinance pace, the local business fallback wage and the
mogul offer schedule were marked as estimates from an average, but no average or
source was named for any of them. Now each is marked as a designed game value,
with a line naming what it reads and balances; no value changes.
