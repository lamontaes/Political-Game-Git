title: Weigh institutional reasons through the shared member vote
---

Members without a view of their own weigh going along with the question before
their body and keeping a law that the same body actually enacted. These reasons
use the existing shared decision table. Members' own views keep their existing
first-pass decisions. Councils now return the shared ballots unchanged rather
than converting present-not-voting rows into yes or no afterward.
