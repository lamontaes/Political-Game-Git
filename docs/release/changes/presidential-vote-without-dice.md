id: presidential-vote-without-dice
impact: patch
section: Changed
title: The presidential vote follows the record, not a dice roll
---

Each state's presidential vote now starts from its certified 2024 result and
moves only with the national mood that every other race reads. It no longer
draws a random national, regional and state swing, so two worlds with the
same record give the same winner and the same margins. A state whose count
ties exactly is no longer settled by a coin toss: its result is recorded
without a winner, its electors are not appointed, and the count waits. Until
the economy's effect on the vote is added, each state votes as it did in 2024.
