title: Name a birthday when you start a life
---

New Game still asks how old you are, and now also lets you name a birthday
month and day. The game writes one date of birth from that age and the
calendar of the place you start in. Lives you already saved keep the
birthdays they had. The hometown question is now "Where are you from?"
