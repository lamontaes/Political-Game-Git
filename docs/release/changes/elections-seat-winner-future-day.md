title: An election for a seat whose term starts on election day no longer stops the game
---

Some elections for seats outside your town stopped the game on election
night. This happened when the new term starts on election day itself, as
with the seat of a member chosen in a special election to serve out a term.
The winner now takes the seat the next morning. A special election called
for a day that has already come is now held the next day instead of
stopping the game.
