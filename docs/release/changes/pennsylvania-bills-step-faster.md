id: pennsylvania-bills-step-faster
impact: patch
section: Improved
title: Worlds in states without their own place data run faster
---

In a state the game generates, such as Pennsylvania, each step of each bill
in the state legislature searched every place in the state for the same first
town. It now finds that town once. In South Fork, Pennsylvania, the first
game year takes 8.8 seconds instead of 20.0, and nothing that happens in the
world has changed: the world after each of ten years is exactly the same as
before.
