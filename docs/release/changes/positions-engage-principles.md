title: Every policy question now says which principles it engages
---

Before, a character could have a recorded conviction and the game had no way
to work out what that conviction implied about any particular bill. A screen
showing what somebody thinks of a question had to guess the connection, and
inside a save a guess looks exactly like a grounded answer.

Each of the sixty-six positions now declares the principles it engages and
which way agreeing with it cuts — consistent with the principle, or against
it. Fourteen principles come with them, chosen so that each is engaged from
several domains rather than restating one question.

Two values and not a scale, deliberately: an author can honestly say which way
a question cuts, and could not honestly say how much. A position that engages
no principle is written with none rather than with an empty list, so a
consumer can tell "nobody has said" apart from "engages nothing".
