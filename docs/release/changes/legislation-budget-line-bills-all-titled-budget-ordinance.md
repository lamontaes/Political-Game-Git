title: A bill that changes one spending line is named for that line
---

A bill to raise or cut one spending line is now titled for it ("Police Funding Increase Ordinance") instead of "Budget Ordinance", so two budget bills on one meeting's agenda no longer read the same. The full budget keeps "Budget Ordinance".
