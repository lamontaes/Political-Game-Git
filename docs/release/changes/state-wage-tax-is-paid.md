title: Every state's wage tax is taken from pay and reaches the state
---

Every state now has one wage tax, set up the same way everywhere. When a
character is paid, the state's share is taken from that pay and recorded in
the state's account. A legislator can file a bill that changes the rate, and a
change that becomes law applies to later pay.
