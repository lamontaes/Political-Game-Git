title: Each state now tracks infant deaths, and abortion laws and dirty air move them
---

Every state and D.C. now keeps an infant death rate, starting from its real 2024
figure. A new abortion restriction raises it about 6% seven months after it takes
effect, and lifting one lowers it by the same amount. Cleaner or dirtier air moves
it too: each 1% less fine-particle pollution than the state started with means
about 0.5% fewer infant deaths.
