section: Changed
title: Recorded schooling selects paid wage peers
---

A town worker's completed schooling can now select a wage offer from the
recorded hourly average of peers' active paid-work agreements in the same
occupation and workplace, using newer completed payments when available.
The offer retains the higher tenure-based rate and legal minimum. Missing
eligible peers retain the existing tenure-based offer.
First-payday baseline agreements remain saved as the source for peer offers;
all first-offer quotes read the same recorded batch before revisions.
The saved compensation note records the contributing records and labels the
average as an estimate; no fixed degree premium is added.
