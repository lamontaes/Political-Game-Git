title: A Places workspace for travel and attendance
---

You can now open Places to see where you are, which short walks and scheduled
activities the game actually offers from here, and what each one would cost in
time. Return home is disabled with the real reason when you are already home.
Inspect opens local government without moving you or changing where you live.
Attend uses the same canonical writers the rest of the game already uses.

Reading Places does not advance time. Only explicit Travel, Return home, or
Attend actions do.
