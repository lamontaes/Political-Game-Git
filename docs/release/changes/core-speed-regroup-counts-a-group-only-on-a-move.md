impact: patch
section: Fixed
title: A year in a large town runs about a seventh faster
---

Each month the game went through every group of households that works out of town and, for each one, counted everyone in a much larger group of households again, though the count was only needed when a household changed groups. It now counts only then. A year at Alamogordo, New Mexico ran in about 280 seconds where it took 331, with every record the same.
