id: x5-a138-traits-from-upbringing
impact: patch
section: Changed
title: A trait added by a content pack starts from a person's upbringing
---

Before, a trait a content pack added was picked for each person by lottery,
so two people raised the same way could start on opposite ends of it.

Now it starts where the person's upbringing leans it. A pack can name the
built-in qualities its trait follows; the example patience pack follows
patience, so someone raised with steady household limits starts patient.
Someone whose upbringing leans neither way starts in the middle.
