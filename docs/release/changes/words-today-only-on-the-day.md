title: A scene says "today" only when it plays on the day it happened
---

A scene's opening narration says "today", "tonight" or "this morning" only when the scene plays on the day of the record behind it, and "yesterday" only the day after. A scene that comes up later opens with a line that names no day, so it can never say "today" about something that happened on Monday when the clock reads Wednesday.
