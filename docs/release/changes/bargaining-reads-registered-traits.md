Internal groundwork. A bargaining sitting now publishes what a member's answer
offers, and reads whatever the loaded trait packs say bears on it, instead of
reading no temperament at all. The legislature declares its own first trait,
which nothing confers yet, so every existing save reads it as unrecorded and
every sitting decides exactly as it did before.
