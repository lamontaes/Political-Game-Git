id: minimum-wage-against-typical-pay
impact: patch
section: Added
title: The game can now read a state's minimum wage against what its workers typically earn
---

Before: researchers find that a minimum wage set well above what a typical worker earns
costs low-wage jobs, but the game had no way to read how high a state's minimum sits
against its typical pay, so that effect had no cause to react to.

After: the game reads each state's minimum wage in force, including any change a state law
makes in play, against the state's own recorded median earnings spread over a full-time
year. The effect on low-wage jobs is now ready on its cause side. It does not move any
number yet, because low-wage jobs are not yet one of the numbers the game keeps for a
place; that is the next piece. Nothing a player sees changes today.
