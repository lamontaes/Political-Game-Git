title: The House apportionment rule is in the game, not yet called
---

The rule that divides the 435 House seats among the states after each census
is now in the game: equal proportions, as federal law sets it. It gives every
state the seats the 2020 Census gave it. Nothing calls it yet; it waits for
state populations the world keeps.
