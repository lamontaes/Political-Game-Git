title: A life in a town split between districts can run for the legislature
---

Before this, someone who lived in a town that crosses several state House or
Senate districts, such as Anchorage, could never run for either chamber. The
campaign screen said the game could not tell which district they lived in. Now
a new life in such a town starts out living in one of the districts that cross
it, and can put their name in for that district's seat. The district seat panel
on the campaign screen says which district the home is in and how long the
character has lived there. It also lets the player pick another of the town's
districts instead, without restarting that clock. An older save in such a town
can pick its district the same way. For now a new life's starting district is
picked by chance until the game knows how to place a home more precisely.

The note about a home in a town split between U.S. House districts no longer
names the file it draws on.
