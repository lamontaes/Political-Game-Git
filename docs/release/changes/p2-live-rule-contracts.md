section: Changed
title: Presidential ballots follow residents and live screens use world contracts
---

Presidential popular votes use the same recorded-resident counter as local contests. Existing eligible people enter the shared nomination engine, and tied or unrecorded preferences create no invented nominee. Presidential qualifications and electoral allocations read sourced data. Developer world constructors live under scenarios; live screens and engines import neutral world contracts. Retired decision flags, duplicate hashing, unused rule declarations and developer status clauses are removed.
