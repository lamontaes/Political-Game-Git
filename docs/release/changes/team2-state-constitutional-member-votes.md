title: State policy amendments record the actual legislature's votes
---

State policy constitutional proposals now record the saved state's actual chamber members through the shared member-vote engine. Dated institution bindings, active seat tenures and recorded vacancies supply the roll call; a congressional delegation cannot stand in for the state legislature. Existing proposal thresholds and modeled-source labels remain unchanged. This bounded A79 migration does not replace the legacy term-limit or policy-filing preflight evaluators.
