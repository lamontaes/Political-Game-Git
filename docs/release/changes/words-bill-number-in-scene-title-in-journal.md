title: The journal names a bill by its number and title, as the scene about it does

The evening before a floor vote, a sponsor asks about "HB 1016"; your journal used to tell the vote as "I voted for the Home Rule Act," so the two read as different bills. The journal now says "I voted for HB 1016, the Home Rule Act." Introduced bills read the same way.
