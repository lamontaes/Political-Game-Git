title: A filing offers the issues that seat's own government decides
---

When you file for office, the positions you can take are now the issues that seat's own government decides in that place. A town board or council seat no longer lists abortion, carbon pricing or cannabis sales, which only a state can change; it lists the local issues the state lets its places act on. A governor or state legislature seat still lists the issues the state decides. Candidates the world files for state their positions on the same list.
