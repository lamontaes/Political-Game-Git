Dev mode's Metrics tab shows how this world opened: for the town, a person, a household, a business and an office, each opening value with how it was made (real data, the world's offset from a published figure, generation, a draw with no record behind it or a number fixed in every world), the code and data row behind it, the record's own source and what replaces a draw or a fixed number.
