id: excise-tax-shared-assessment
impact: patch
section: Fixed
title: Filed excise taxes use their adopted terms
---

An excise proposal filed from an eligible office now records the tax question and
its exact levy terms. Declaring a taxable occurrence uses the shared tax path to
assess what is owed. The existing payment system collects only available money,
and loading a save or repeating the declaration does not assess it twice.
