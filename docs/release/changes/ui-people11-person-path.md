section: Fixed
title: The game no longer says someone is elsewhere when they are in the room
---

When there was nothing to talk about with somebody, the game said they were
"not somewhere you can talk to them right now" — even when they were standing
in the room with you. It now says what is actually true: there is no
conversation established with them here yet.
