title: Other states' governors give their State of the State again.
---

Since other states' officials stopped being built as people nobody had met, no other state's governor gave the yearly address. Each one now gives it on their state's day from the same draw that would build them, and only the result is kept; nobody is built. A state whose session convenes after the game's first day gives its 2025 address in the world.
