title: Record policy amendment ratification through actual state chambers

The scheduled Article V policy state action now uses the existing actual-state
vote recorder. Each chamber retains its own declared threshold and quorum, actual
members and reasons. All50states now have bindings; source-silent elected-member
majorities are explicitly ESTIMATE, while cited supermajority fractions remain.
Unimplemented research conditions are disclosed rather than claimed enforced. A missing actual body leaves the state
action unrecorded instead of substituting Congress or a pooled majority. The
existing term-limit callers retain their public APIs and considerations through
the same extracted recorder.
