section: Changed
title: Record policy amendment ratification through actual state chambers
---

The scheduled Article V policy state action now uses the existing actual-state
vote recorder. Each chamber retains its own sourced threshold and quorum, actual
members and reasons. A missing body or unsupported legal rule leaves the state
action unrecorded instead of substituting Congress or a pooled majority. The
existing term-limit callers retain their public APIs and considerations through
the same extracted recorder.
