section: Fixed
title: State laws passed in 2025 take effect the set time after the session ends.
---

In the 18 places whose new laws take effect a set time after the legislature adjourns, a law passed in 2025 counted that time from the day it passed, because the game had no 2025 adjournment dates. It now counts from each legislature's real 2025 adjournment. Where a place has none, it counts from the end its law sets, or from a labeled estimate.
