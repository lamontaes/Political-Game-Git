---
id: world-home-prices-from-housing
impact: minor
section: Changed
title: Home prices now come from your town's own market, and a home sells for what it is worth today
---

Every home value in the game used to follow a published state price index looked up by date. Now each town keeps its own price level that moves each month with what its people earn, the mortgage rate, and how many households bought against how many homes came up for sale, and the years before your start run the same way. A home that sells, whether its owners move away, die or lose it to foreclosure, now goes for its value that month instead of the value it had when the world began, and a home bought during play keeps changing value afterward. Metrics' typical home value, property tax bills and mortgages all read the same price.
