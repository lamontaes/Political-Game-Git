title: A recall petition's signatures are counted against the state's own base.
---

When neighbors sign a recall petition or vote on one, every adult in town decides the same way, whether they are a named person or part of the wider population. The number of signatures needed is now the state's percentage of the voters its rule names (votes cast for the office, or at the last town election, from the recorded results), always a whole number of voters.
