title: Voters everywhere are simulated, so campaigns, candidates and conditions win and lose votes
---

Every race for Congress, the Senate, governor, the state legislature and president is now counted county by county. Each county's voters are split into strong partisans, weak partisans, leaners and independents in the mix that matches how it really voted in 2024. Party still counts most, but not for everyone: a scandal, an experienced or unknown candidate, how much a campaign spends, the economy since you started, a midterm year and changes to the voting laws now move votes, mostly among weak partisans and independents. Races in other places run the same way. Each race keeps its votes by county and group, along with each candidate's reasons.
