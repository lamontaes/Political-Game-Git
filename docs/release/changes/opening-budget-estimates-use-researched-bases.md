section: Changed
title: Opening budget estimates use researched bases without a random spread
---

A county's, city's or unsurveyed territory's opening budget now uses the
existing researched average and population calculation directly. An extra
random spread no longer changes revenue, spending or debt. Governments with
their own read figures retain those values. Existing saved budgets are kept.
