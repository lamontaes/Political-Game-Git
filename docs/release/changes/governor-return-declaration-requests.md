id: governor-return-declaration-requests
impact: patch
section: Changed
title: Department heads ask for the governor’s decision differently as the deadline approaches.
---

A governor revisiting an emergency declaration can hear what the counties need to know, what advice could still be checked and when the offer will expire.

The governor can answer the department head directly about notifying counties, hearing from public health or waiting for another forecast. Revisiting a previous answer retrieves the decision already made.
