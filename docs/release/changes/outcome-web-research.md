Research only. docs/research/outcome-web-2026-09-28.md records how the game's
areas affect each other and how strongly: about 90 links across education,
health, the safety net, housing, transport, public safety, the environment, the
economy, rights and democracy. Each link is checked against causal research and
given a strength, an anchor size, a shape, timing and the group it falls on. It
also lists the effects the game must not invent. 04 SYSTEM SPECS part 5 turns
it into the build rule for the outcome web. No code changes.
