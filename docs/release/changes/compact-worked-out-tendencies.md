title: Saves stay smaller as the country's officeholders weigh their careers
---

The temperament a person has from their upbringing, written down the first
time a decision of theirs needs it, uses a compact form in new save files.
Loading rebuilds each record with the same person, trait, value, date, note and
identifier, so every trait reads the same after a save as before it. Older
saves still open, and a temperament that changed during play keeps its full
record.
