id: american-english-everywhere
impact: patch
section: Fixed
title: The game is written in American English throughout
---

Color, center, neighbor, behavior, canceled, gray: the game's words, its notes,
and the guides its writers follow now spell things the American way. Dates read
month first, so a day shows as September 22, 2026. Population density on the
map is given in people per square mile instead of per square kilometer.

A check now reads every file in the project for British spellings, day-first
dates and metric measurements in player text, so they do not creep back. Saved
games are untouched: the few words a save stores keep their old spelling, and an
old save still loads.
