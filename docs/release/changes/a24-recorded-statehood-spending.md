id: a24-recorded-statehood-spending
impact: patch
section: Fixed
title: Statehood no longer subtracts a frozen Medicaid aid estimate
---

Budget adoption no longer invents a financial certificate from cash held or
subtracts a fixed fiscal-2024 Medicaid amount. Actual saved program payments
continue to supply the government's spending rows. Historical certificate
bytes remain readable when a saved game continues; they authorize no payment.
