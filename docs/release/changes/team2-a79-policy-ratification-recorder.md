section: Changed
title: Admit saved policy amendments to actual state chamber votes
---

The existing actual-state ratification recorder now accepts a saved policy
amendment. It uses the same constitutional considerations, actual dated members,
separate chamber requirements and sourced quorum rules. Unsupported rules or
missing institutions still leave the action unrecorded. The Article V policy
callback migration remains a separate pending ownership transfer.
