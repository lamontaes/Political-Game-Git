id: ph-official-views-sources-restored
impact: patch
section: Changed
title: Official-view weights are labeled placeholders again where no source exists
---

Before, nine weights for blame, visibility and how hard a law landed on a voter
had been relabeled as estimates from an average, but no average or source was
named for any of them. Now the original placeholder labels are back; no value
changes. A weight returns to an estimate label only when a real average and its
source are recorded with it.
