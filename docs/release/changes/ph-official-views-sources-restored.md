impact: patch
section: Changed
title: Official-view weights are marked as designed game weights
---

Before, nine weights for blame, visibility and how hard a law landed on a voter
had been relabeled as estimates from an average, but no average or source was
named for any of them. Now each is marked as a designed game weight, with a line
naming the record it reads and the behavior it balances; no value changes.
