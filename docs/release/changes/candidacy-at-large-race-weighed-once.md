impact: minor
section: Changed
title: People thinking of running for an at-large board weigh the whole race, so its field is no longer crowded.
---

Someone weighing a run for one seat of an at-large race now counts everyone already running for its other seats, so a three-seat selectboard race draws about as many candidates a seat as a one-seat race, not twelve.
