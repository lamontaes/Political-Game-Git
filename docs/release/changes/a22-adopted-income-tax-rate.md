impact: minor
section: Fixed
title: Paycheck taxes use the adopted flat income-tax rate
---

A state income-tax bill with an adopted flat rate and annual taxable-income
threshold uses those terms on actual paychecks. A missing deduction remains a
labeled estimate. Existing tax-year timing, withholding receipts and saved
liabilities are preserved.
