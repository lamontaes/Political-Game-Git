title: The replies you are offered are no longer the same answer worded several ways.
---

Each reply now does something different (answers, adds a fact, turns the question back, puts it off, asks, agrees, comforts), and a talk or scene never offers two of one kind. Where there are not yet four different answers to offer, the talk plays with the ones it has and the gap is listed until the words are written.
