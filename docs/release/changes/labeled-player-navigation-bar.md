title: The seven main player sections now stay labeled along the bottom of the game
---

The seven main player sections now stay labeled along the bottom of the game.
The player's portrait opens a smaller menu for Save, Guide, Options, and
Return to title. On narrow screens the sections use two rows; the pin rail
clears the measured bar height. The proposed Alt+Shift+1–7 shortcuts remain
marked for overnight browser and desktop validation.
