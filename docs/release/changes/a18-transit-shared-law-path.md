title: A state transit law now reads like every other spending law.
---

A passed state transit law no longer has its own separate route. Its money is shown as one spending authority, with the same dates, payments and service as any other program, and a rider's completed trip is recorded the same way as other public services. Saved games with a transit law keep working.
