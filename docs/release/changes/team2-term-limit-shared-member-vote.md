title: Congressional presidential term-limit proposals use the shared chamber vote
---

Congress saves a presidential term-limit amendment proposal before its members
vote through the shared chamber decision path. A failed proposal keeps its actual
rejection rollcall. Existing constitutional thresholds, amendment terms and state
ratification timing remain unchanged. State term-limit callers retain their
current decision path and reuse the shared rationale-weight table.
