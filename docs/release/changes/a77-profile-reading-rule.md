title: Town profiles declare their existing single-vote reading interval
---

The town council game profile explicitly records zero elapsed days between
readings for its existing single adoption vote. The shared bill driver reads
this rule alongside the profile's declared quorum. The profile remains labeled
as authored game procedure; it introduces no extra reading or waiting period
and makes no claim about an unread town charter.
