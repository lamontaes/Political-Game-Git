The engine that weighs whether somebody comes to hold a political view has had
one caller since Stage 4, the demo, so a world could load a full catalog of
propositions and still hold nobody with an opinion about any of them. This adds
the quarterly pass that would form one: it picks a proposition somebody has
actually been exposed to since they last concluded anything about it, runs the
engine and writes the belief.

Nothing changes for a player yet, deliberately. The pass is not registered in
the transition registry, because no save should gain a scheduled item that can
do nothing, and its factor builder supplies nothing because no proposition
declares which principles it engages — so there is no honest way to say which
direction anything points. Both land together with the first factor source.
