Dev mode's Metrics board shows a Loans panel for the player's household: each loan application with the income the lender read, the amount asked and offered, and the answer; and each month's bill on each loan with the amount due, the borrower's cash that morning, what was paid, and the payment or missed-payment record. Nothing changes for the player.
