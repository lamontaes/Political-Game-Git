section: Changed
title: Court review requires a recorded claimant and filing
---

A matching law no longer receives an automatic ruling from the precedent table. A personal challenge must name a saved court, a real claimant, their complaint, and a prior stamped consequence naming them under that law. The filing is saved before the existing review writer runs; a ruling points back to that filing.

The reader admits stamped events and saved legal-outcome consequences. Organization claimants, other harm-record families and a player-facing filing entry are not included. Positive filing inputs in the unit tests are explicitly authored compliance burdens, not native gas-law effects. The national enactment test retains its full canonical save check; the legacy authored state-law fixture uses only a JSON data round-trip.

The complete changed court test file passed six tests with unchanged limits. Scoped types found no diagnostics. The A101 static check moved from zero of one on the pinned main source to one of one on this branch. Earlier failing fixture and setup receipts are retained.
