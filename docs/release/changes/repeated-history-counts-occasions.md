title: Repeated history counts occasions rather than records
---

Repeated formative history is what proposes a change to a character, and it
was measured by counting interaction records. Several records can carry one
event, so one thing happening twice and one thing recorded twice looked the
same. It now counts distinct occasions; a record the history cannot tie to an
event still counts as its own, because the record is then the only evidence
that it happened.

This does not change which change is proposed. That is still the first entry in
the personality catalogue whatever the occasions were about, which is recorded
as a defect and filed as a question rather than guessed at.
