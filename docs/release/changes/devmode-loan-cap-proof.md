title: Dev mode proves the consumer loan cap reaches the lender
---

Dev mode can introduce bills on a yes-or-no policy question, such as the consumer loan rate cap, and have the members vote down any repeal while the world runs. A run in a town with a lender shows the lender reading the cap, so the law counts as fully wired.
