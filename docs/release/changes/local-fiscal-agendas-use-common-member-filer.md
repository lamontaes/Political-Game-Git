title: Local fiscal agendas use the common member filer
---

City and county agenda intakes now use the same member filing mechanism as other legislatures. Recorded principles, actual seats, local authority, preemption and cooldowns govern proposals. Missing numeric references still allow a reasoned plain bill, without invented appropriations.
