title: Missing paid-leave rates use sourced program peers
---

Unread paid-leave premium and replacement rates use comparable sourced program
rates instead of a world-seed draw. The estimate ranks program peers by region
and household income, preserving read rates, caps and the existing payment path.
It remains labeled as an estimate until the law's own rate terms are admitted.
