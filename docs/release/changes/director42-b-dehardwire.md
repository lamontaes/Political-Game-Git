title: Filed measures keep their world identity from drafting through the floor
---

An ordinary legislative life no longer depends on one fixed bill number or a
component-owned measure identity. The jurisdiction's recorded chamber and
numbering state now assign each filed measure its designation, while the
office, members' room, working paper, fiscal note and vote all follow the same
saved measure record.

The chosen authored deliberation remains deterministic for the same world and
must agree with the filed measure and institution before the room is offered.
Different supported worlds may select different authored measures and numbers.
Saving and reopening preserves the selected measure, designation, cast and
working record instead of selecting them again.

The runtime census now guards the ordinary-player import graph against newly
unclassified world-instance literals. Existing authored and development-only
fixtures remain classified rather than being treated as ordinary generated
play.
