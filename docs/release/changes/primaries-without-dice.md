---
id: primaries-without-dice
impact: patch
section: Changed
title: Party primaries follow each candidate's standing, not a dice roll
---

A party primary for Congress or a state legislature is now decided by each
candidate's standing with the party's voters: a sitting member first, then
someone the party asked to run, then anyone else. The roll that used to
stretch or shrink each candidate's vote is gone, so the same field gives the
same nominee in every world. A runoff now goes to whoever led in the primary.
An exact tie is no longer settled by the order of names: the tied candidates
are recorded as tied, nobody is nominated, and the state must settle it.
