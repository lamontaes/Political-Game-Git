title: A colleague who asks about several bills on one evening hears your answer on each
---

When a colleague asks for your vote on several bills the evening before a floor day, the one conversation now takes up each bill in turn. Before, you answered only the first, and the others went unanswered. Each answer is kept on its own bill, and that bill's roll call reads it.
