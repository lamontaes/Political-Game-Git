title: Dev mode changes laws, steers people and runs "what if" experiments
---

Dev mode, opened from the play screen, can pass or repeal any law at any level, make any person take a choice the game offers them, cast any vote or sign or veto a bill, jump time, trace any record and watch the town month by month. Its first saved experiment raises every public salary to a $70,000 base. It replaces the old developer page.
