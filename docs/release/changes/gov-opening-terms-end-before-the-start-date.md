title: Every official starts the game in a term that is still running
---

A new game used to open with most state and federal officials, and many in town, in a term whose listed end date had already passed, so dev mode's Trace and a person's card showed an ended term for someone still in office. Every seat now opens with the term in office on the day the game starts, from the office's own start day to the end its election calendar gives.
