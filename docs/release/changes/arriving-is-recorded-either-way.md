title: Making a journey no longer strands the meeting it was booked for
---

An outing appears in the calendar as two rows: the journey, and the thing you
are going to. Carrying out the second one travels and attends in a single
action. Pressing the journey's own row instead — the first control on the
screen — completed the travel and then left the meeting refusing to happen,
saying the game could not tell where you were standing. It stayed refused for
the rest of that life. Asking a party for an organizing meeting, walking to it,
and then being unable to attend it happened on the first press.

Arriving somewhere is now recorded the same way whichever control you pressed,
so the meeting at the far end can be attended. A place the game has no authored
route to is still refused exactly as before; nothing new was invented to reach
it.
