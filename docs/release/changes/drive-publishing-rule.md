Development documentation only; nothing in the game changes.

The project publishes status documents to Drive, and the convention for replacing one was to bin the previous copy so a reader could never be unsure which was current. That convention destroyed a reply left as a comment on a superseded copy, and broke an outside checkpoint that pointed at another. Superseded documents are now renamed and moved to an archive folder, which keeps every link and comment resolving and still leaves exactly one unmistakable current render.

Written down in docs/DRIVE-PUBLISHING.md for every lane that publishes.
