section: Improved
title: Weekly pardon reviews stay quick in later game years
---

Each week, every sentence up for a pardon review asks which governor holds
the pardon power. Answering that read every state's records and every event
again for each sentence, so the cost grew with the number of people in
prison. Each world's governors are now read once. The illness lookups that
find who is already ill, and a crisis record by its id, also keep indexes
that grow with their lists. In South Fork, Pennsylvania, game years six to
ten take 7.9, 12.6, 8.2, 12.8 and 14.0 seconds less. The world after each of
ten years is exactly the same as before.
