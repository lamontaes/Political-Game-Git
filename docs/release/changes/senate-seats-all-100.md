title: A new world seats all 100 senators, and the opening card names any empty seat
---

A new world could open with a Senate or House seat left vacant by a draw,
and the opening card's "In the year" line counted only the parties'
members, so it showed 99 senators with nothing about the hundredth. Now a
new world seats a member in every seat of both chambers; a seat is vacant
only when a later record, such as a death or a resignation, makes it so.
When a seat is empty, the opening card names it ("a Hawaii seat is
vacant"), so its counts always add up to the whole chamber.
