title: A state's figures now come from one place
---

Metrics' state unemployment, jobs and pay used to be summed from the town's regions, while the state's own session agenda read a different set for the same state and month. The country tier now keeps each state's figures by month (this year, last year and each December), and Metrics, the state's agenda and the jobs other states offer all read that one row. The state's jobs row counts the people who live in the state and have a job, wherever they work, so it is now labeled "Residents with jobs" (it was "Jobs").
