section: Changed
title: The game opens at home on the first evening
---

The President's address no longer plays in its own box over its own pictures before play begins; the game opens at home that evening, with the night's news on the table. The address is still given and recorded, the press still prints it, and people still bring it up. It plays again as a scene in the talk box once the director stages it.
