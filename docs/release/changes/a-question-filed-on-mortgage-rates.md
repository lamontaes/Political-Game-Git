title: A research question is filed on how mortgage rates follow the policy rate
---

Home prices in the game move with changes in the 30-year mortgage rate. Where
the game carries only the policy rate, it uses that change as a labeled
stand-in. The new question asks how much of a policy-rate change reaches the
mortgage rate, so the stand-in can be replaced with a measured value.
