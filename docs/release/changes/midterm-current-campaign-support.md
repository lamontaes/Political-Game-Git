section: Changed
title: Missing new presidential views can read current recorded campaign support
---

When no other official has a saved support view, missing re-recorded presidential
standing can now use the latest canonical support shares of current same-party
candidates in active, pending contests. The result is labeled an estimate and
names its actual candidates, campaign and support-state records, mean and spread.
Duplicate references to one candidate's metric scope count once. Completed or
canceled contests do not supply current standing. These contest shares are
comparable estimates, not national adult-contact counts.

Actual re-recorded presidential views still use the same recorded adult cohort
and dated inauguration baseline. A wholly empty comparable-record pool remains
a producer gap; this checkpoint does not create support records or wire estimate
details into the player screen.
