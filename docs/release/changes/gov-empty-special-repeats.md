id: gov-empty-special-repeats
impact: patch
section: Changed
title: A seat nobody ran for follows the place's own law, and an empty special election runs again
---

When no one runs for an office, the place's law for that office now decides: the holder serves on, or the seat goes vacant. An empty special election no longer leaves the vacancy stuck; the next special is set from that day, and each result keeps its reason.
