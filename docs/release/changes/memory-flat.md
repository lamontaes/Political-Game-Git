section: Changed
title: A town uses less memory, and "Generate a town" no longer runs out
impact: patch
---

"Generate a town" on the bench now builds the same two-level town as "New life", so a month of play no longer runs the bench out of memory. Old news, outcome effects that have stopped, and regional figures from past years are let go as the game runs, so a long game grows more slowly.
