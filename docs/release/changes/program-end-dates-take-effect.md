id: program-end-dates-take-effect
impact: minor
section: Added
title: A law that ends, extends or repeals a program now changes what can be funded
---

When a law set an end date for a program, extended it or repealed it, the
program stayed open for new spending bills as if nothing had passed. Once the
program's last day under the law has gone by, a new spending bill can no
longer be written against it, and the list of programs says which law ended
it. A later extension replaces an earlier end date, but nothing brings back a repealed program, and a law ends a program only in the place that passed it. The law's page says when
the program ends or ended.
