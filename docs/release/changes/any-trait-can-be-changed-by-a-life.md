The machinery that lets what happens to somebody change their temperament now
works for any trait a pack declares, not only the five built in, and a trait
pack compiled into the build is seeded for everybody without other code naming
it. Nothing in play targets a new trait yet, so no player-visible behavior
changes; this is the route the researched trait catalog will land by.
