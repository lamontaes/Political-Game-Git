title: A smaller newsroom covers less, and an owner's outlets run one another's stories
---

When an owner lays off reporters, the outlet now takes on fewer stories, in step with the reporters it kept. Once nobody is left, it covers nothing. An owner that orders its outlets to share now has each story run in its other outlets, credited to the newsroom that reported it. A sibling outlet carries a story only if it is relevant to that outlet's own readers. How often owners do this is still a placeholder awaiting research.
