Counted deaths now fall on every age the town's tables owe them to. A month's deaths used to go in one lump to the oldest group of people, so nobody under sixty-five died for a year in some small towns and the first year ran well under the tables. Each group now pays no more than it owes, and a household record that is ill in part still counts for its other households.
