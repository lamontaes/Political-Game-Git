title: A campaign's ads, mail and polls no longer spend the money set aside for circulators
---

A rival campaign's ads, mail and polls now spend only the money it has not set aside for an event, a poll or circulators, so its circulators are always paid and a played year no longer stops on an overdrawn campaign account.
