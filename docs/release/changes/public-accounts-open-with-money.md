title: Governments start with money in their accounts
---

A new game now opens every government's account with a starting balance
instead of nothing: the federal government, each of the fifty states, and each
local government the game runs. Each state also starts with its own generated
tax and service settings, so a funded program has money to draw on from the
first day.
