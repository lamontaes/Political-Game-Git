id: every-draft-has-fiscal-note
impact: minor
section: Added
title: A fiscal note accompanies each draft and filed bill
---

The docket now shows a fiscal note for a draft before filing and for its saved
bill afterward. It lists each section's scope and stated amount and identifies
whether the amount is an appropriation, an authorization ceiling, or a charge
per covered event. When a total cost or receipt needs an activity count or a
payment record the world does not have, the note names that missing input
instead of showing zero. Reading the note does not move money or enact the bill.
