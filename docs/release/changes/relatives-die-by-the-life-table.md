section: Changed
title: Parents and grandparents before the start die by the game's own life table
---

A grown-up life's parents and grandparents used to live to a set age between
78 and 90. Each one now lives until the game's own mortality says they die,
counted from the birth of their youngest child. The game uses this same rule
for everyone once play starts. Across the 56 places, at 40 about nine in ten
grandparents and one in five parents have died before the start.
