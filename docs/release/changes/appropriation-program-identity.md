id: appropriation-program-identity
impact: minor
section: Fixed
title: Appropriations keep the program they fund
---

Enacted appropriations for two named standing programs in one state now keep
separate program records. A later supplemental appropriation for the same
program adds its own spending authority to that program. Where a docket bill
does not identify one program target, enactment no longer assigns its aggregate
ceiling to a generic state program.
