title: Session budget requests await the current governor's choice
---

A regular-session intake opens a budget request when the current governor has no decided request. The bill files after that governor records a choice; a lapsed request cannot file. Biennial clauses retain each year's adopted spending lines, with an explicitly unchanged current-services line only when the second year's adoption is absent.
