title: The journal says a race was close only when the count shows it
---

A candidate's journal now says "It was very close." or "It wasn't close." only when the result's vote totals bear it out. Before, those lines were picked by win or loss alone, so someone who ran unopposed could write that it was very close. A race with one candidate now reads "I won." or "We won.".
