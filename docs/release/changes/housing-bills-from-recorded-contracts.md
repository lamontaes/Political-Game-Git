impact: patch
section: Fixed
title: Household housing charges come from their recorded contracts
---

New food-and-bill charges exclude the old estimated housing share. Actual leases and mortgages charge housing separately; missing housing contracts no longer create estimated rent. Existing charge histories stay intact, and old living-cost flows change prospectively. Nonhousing costs remain a marked stand-in while regional spending data is unavailable.
