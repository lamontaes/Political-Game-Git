Missing reference population and voting figures can show labeled estimates from the current game records. Missing two-bedroom rent figures can show the average of active recorded leases. Each estimate names its contributing places or homes and observed spread. A fresh opening with no leases still needs its admitted rent input; this draft does not complete that case.
