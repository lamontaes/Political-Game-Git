title: State legislatures find their seats once a day
---

Each game day, the state legislature's turnover checks which seats are up in
each election year it looks at. Every check read the chamber's seats again,
and each reading walked every member the chamber has ever had, so the check
cost more with every election. A chamber's members and seats are now read
once for each moment of the world. Every seat and member comes out the same.
