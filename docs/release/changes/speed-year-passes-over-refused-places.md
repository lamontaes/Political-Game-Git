id: speed-year-passes-over-refused-places
impact: none
---

`npm run speed:year` passes over a drawn place the world refuses to open (every adult lives in group quarters, so there is no one to play): it names the place, draws the next one from `<seed>:1`, `<seed>:2` and so on, and prints the seed it used. The run's own first draw is unchanged, and a place asked for by `--place` is still built as asked.
