title: Towns newer than the 2020 Census lists have a congressman and state legislators
---

About five hundred towns, most in Indiana, Pennsylvania and Virginia, had no U.S. representative or state legislators, because the Census district lists predate them, so there was no legislative race to file for. Each now sits in the districts most of its county's other towns are in, marked as an estimate.
