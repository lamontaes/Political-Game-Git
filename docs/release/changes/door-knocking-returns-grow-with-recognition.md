title: The doors return more once people know your name
---

An afternoon on the doors used to be worth the same for everyone. A candidate
nobody has heard of now gets about half as much from their first afternoons.
Each afternoon makes the next one worth a little more, up to the full amount,
and a candidate who has won races before starts ahead. These amounts are
placeholders until the real ones are known.
