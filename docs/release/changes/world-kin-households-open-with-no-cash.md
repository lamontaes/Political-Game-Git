title: Relatives living around the town no longer start with empty pockets
---

The family members the game places in the county around the player's town used to start the game with no money at all, while paying rent and groceries from the first day. They now start with what a household at their pay usually keeps in the bank, the same as the county's other households, so a relative the player meets has savings that match their life.
