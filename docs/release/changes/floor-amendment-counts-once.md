id: floor-amendment-counts-once
impact: patch
section: Improved
title: State legislatures weigh floor amendments much faster
---

Before offering a floor amendment, each legislator counts how the chamber
would vote. Every member's count used to decide the whole chamber again, two
or three times for each question they might raise, so the work grew with the
square of the chamber's size. A colleague's vote on the same reading of a bill
is the same whoever counts it, so each reading is now decided once, and only
the counting member is decided again. In South Fork, Pennsylvania, the first
game year takes 14.4 seconds instead of 36.6. Nothing that happens in the world
has changed: the world after each of five years is exactly the same as before.
