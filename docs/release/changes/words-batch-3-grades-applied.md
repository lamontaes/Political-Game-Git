Following the owner's batch 3 grades, lines no longer point at things nobody set up ("the list", "the page", "a hearing, then"), drop stock tags like "That's real", and name the place instead of "this town" where the scene knows it. Mayors open their address in different ways, a job offer says the pay before your first day, and journal entries about finding work are told as moments.
