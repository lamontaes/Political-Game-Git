title: Appointed board members answer clemency requests from their own records
---

Active, living appointees now answer a saved clemency petition through the
existing clemency decision. Each vote saves its actual member, membership and
decision trace. A board answer records those voters and the vote events; repeat
delivery and SaveContinue preserve the original records.

The existing appointment profile must supply an explicit quorum and action
threshold. The current admitted path uses Louisiana's sourced four-member
quorum and four favorable votes (La. R.S. 15:572.1(E), the existing cited profile).
Departed members cannot provide the quorum, and three recorded votes cannot
authorize an answer. The changed consumer test does not establish Connecticut panel assignments, Texas voting
eligibility, all-state board coverage or the three remaining positive fixtures
in the existing clemency decision tests. No missing legal rule or actual person
is supplied by this consumer.

Validation: the complete changed consumer test file passed both cases, including
the actual court sentence, appointment, member decision, quorum and replay joins.
Scoped strict types and changed lint/format checks passed. No full suite, browser,
LOAD or official gate was run.
