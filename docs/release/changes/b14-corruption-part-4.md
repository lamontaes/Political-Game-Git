title: Rivals can read public records left by corruption acts
---

An opponent can read a public contract award, disclosure filing or payroll posting
that an act actually left. The opponent decides whether to refer the record or
set it aside. Referring it links the record to a matter and opens the existing
complaint process; the public record alone does not establish misconduct.
