title: A meeting due now no longer freezes the day
---

A life could get stuck on one day. A fourteen-year-old in Wellsboro,
Pennsylvania had a meeting she had arranged starting at six o'clock. Time will
not step over a commitment like that, and a child's moment offered no way to go
to it. So "Let the year run on" came back unmoved, 1,764 times in one lives
run. The same happened to a fifteen-year-old in Washington, D.C.

Children now get the same "Attend" choice beside the moment that adults got.
Going to the meeting lets the year run on again.

A commitment whose time has already passed now says so plainly and can be let
go, instead of showing an error with no button. That happens with meetings an
older version carried past. When there are several, one choice lets go of all
of them.
