id: state-property-and-payroll-tax
impact: minor
section: Added
title: A state's own property, sales and payroll tax can be filed, passed and felt
---

A seated state legislator can now file a state property, sales or payroll tax,
and the state legislature can pass it. Once it is in force, a state property tax
assesses every household home in the state each year, and a state payroll tax
taxes each paycheck paid by an employer in the state. The tax lands on the named
person who owns, rents or earns, and repealing it stops the bills.
