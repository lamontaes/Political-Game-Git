Adds the shared court, seat and rule records for the judiciary work. A court
size reduction consumes vacant seats first, then retires occupied seats as
their tenures end. Retired seat IDs and tenure history remain in the save; a
later increase creates new seats instead of reopening retired ones.

This model has no new player route in this change. Opening judges, philosophy
and the court roster are separate follow-up work.
