title: State legislatures no longer hold extra empty seats where two lists spell a district differently.
---

Maryland's House had 150 seats for 141 members, Massachusetts's Senate 48 for 40, and three more chambers one to three extra, each extra seat voting with a guessed party. District names are now compared by one rule, so each chamber seats its members once.
