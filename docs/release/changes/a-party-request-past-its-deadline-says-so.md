title: A party request past its deadline no longer offers Accept
---

When a party or campaign asked for your help with something like a door
canvass, the request kept its Accept button after the time to answer had
passed. Pressing it only said it was too late.

A request now stops offering Accept once you would have had to set out for it.
It says who needed the answer and by when, for example "Monroe County Democrats
needed an answer by January 7, 2026, 6:10 PM; that has passed." The same line
shows on the Calendar. When the day passes, the request is recorded as having
lapsed, not as something you turned down, and it reads the same after you save
and load.
