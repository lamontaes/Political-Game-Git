title: Statewide races follow the state's own lean, with incumbency counted once
---

Statewide races such as governor no longer swing far from how a state votes because voters' liking for incumbents was counted twice. The incumbency advantage now comes once, from the candidate's public standing, and each voter's personality moves them a little around it.
