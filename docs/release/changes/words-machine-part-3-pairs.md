The owner's rules about a line and its reply can now judge each answering line together with the line it answers, so a reply is no longer judged with its ask stripped off. A "no" after one line keeps the reply from being offered after that line only, through the one table the picker reads. No rule bars anything yet: the first verdicts wait for the Words lead.
