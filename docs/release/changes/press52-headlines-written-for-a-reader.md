title: Headlines are written for a reader, and three papers no longer run the same sentence
---

A story's headline used to be the simulation's own note to itself, printed as though a person had written it. A party founding read "2 organizers publicly decided to form The Commons Party." — a numeral where a newspaper writes a word, a count where the record holds names, and "publicly", which is the game telling you that what you are reading is public. Every paper rendered that same line, so three outlets covering one story printed it word for word. Headlines now spell a count out, name the people the record names when it names exactly them, and drop the words that only describe the record. And the outlets write differently because they already are different: a paper with the staff for it names people, a broadcaster keeps the count because a line read aloud has no room for both, and an outlet whose readers are not standing in the place says which state it was. No headline contains a word the record does not — the verb is always the one the game wrote down.
