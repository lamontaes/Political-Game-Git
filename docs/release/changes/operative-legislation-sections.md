title: Selected appropriation sections retain their stated effect
---

An appropriation filed with selected sections keeps those sections in order and
preserves the selection through Save and Continue. The filing action refuses a
selected duty the world cannot carry out. A state appropriation's
available-through date follows its enacted clause. The existing Alaska transit
service mandate remains a complete package because its service reader requires
all of its sections together.
