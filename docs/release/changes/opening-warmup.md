title: A new game opens with the country already running
---

A new game now builds the world a month early and lets it run to the start date, so the budget in force, the cabinet, the economy's figures, people's health and partners, and the first weeks of the town's courts, press and agendas already exist when you arrive. Building a new game takes about half a minute longer. You do nothing in those weeks: no job change, move or filing happens for you, and nothing from them shows in your journal.
