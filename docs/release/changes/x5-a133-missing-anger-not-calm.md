title: Unrest no longer ends just because nobody measured the anger
---

Unrest in a state used to count as over whenever no reading of public anger
was on hand, as if no news were good news. Now it ends only when the anger
read for that quarter has fallen back to the line, or when the quarter's
reading found nothing left to carry. A threat made during that unrest stays
open the same way, rather than lapsing because a reading was missing.
