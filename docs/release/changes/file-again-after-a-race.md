impact: patch
section: Fixed
title: A finished race no longer stops a character running again
---

Once a character's race was decided, won or lost, Campaigns never offered
another filing, so a council member could never go on to run for the
legislature. The finished race is still shown, and the next filing is offered
beside it.

The result now speaks of the candidate with their own pronouns, and marks
them in the tally as "you" rather than "them". In an allegation story, only
the people the allegation is about are asked to respond, so an accuser is no
longer printed disputing her own account.
