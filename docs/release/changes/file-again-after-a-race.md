title: Election results use the candidate's own pronouns, and accusers no longer deny their own allegations
---

The result of a race now speaks of the candidate with their own pronouns, and
marks them in the tally as "you" rather than "them". In an allegation story,
only the people the allegation is about are asked to respond, so an accuser is
no longer printed disputing her own account.
