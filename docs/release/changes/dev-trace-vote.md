title: Dev mode's Trace of a bill's vote reads in words
---

On a bill's page, dev mode's Trace opens the record (the chambers' rolls, each name a button), why the chosen member voted as they did (each recorded reason and which way and how hard it pulled, in words) and what came of it (where the bill stands and who signed or vetoed it). It replaces the raw reasons text the dev trace used to print for a vote.
