id: laws-snap-maximum-reaches-food
impact: patch
section: Changed
title: A higher SNAP maximum shows up in what households buy, counted once
---

When Congress raises the SNAP maximum, each qualifying household's benefit rises, and a household that could not afford all of its groceries buys more of them. That is now the one place the change shows: the town's separate food-insecurity figure no longer moves on its own for the same raise, so the effect is not counted twice.
