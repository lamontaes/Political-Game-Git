section: Changed
title: Every state has its own capitol
---

Each state now shows its own capitol building instead of one shared dome.
Texas's is pink granite, Nebraska's and Louisiana's are towers, New Mexico's is
round, Hawaii's stands on columns shaped like palm trunks, and New York's looks
like a castle. D.C. shows the John A. Wilson Building, where its Council meets,
and Puerto Rico, Guam, the U.S. Virgin Islands, American Samoa and the Northern
Mariana Islands each show their own legislature. For now each is a daytime
picture at every hour; morning, night and rainy versions follow.
