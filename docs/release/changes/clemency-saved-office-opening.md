title: Saved governor desk openings reach existing clemency decisions
---

An actual saved governor-desk opening reaches the existing request decisions for that office’s running cases. Petitions follow the defendant’s durable decision and preserve the original request’s holder. Repeated delivery and stale saved terms do not create another request.

Weekly request creation remains while the complete court-clock replacement is proved.
