title: Other states' legislatures no longer build every member as a person nobody has met.
---

Another state's session decided its laws by building each of its legislators and its governor as a recorded official, about 7,500 a year nobody had opened. Each member's position is now read from the same draw that builds them, so the session's results stay the same and nobody is built until the player meets or opens them.
