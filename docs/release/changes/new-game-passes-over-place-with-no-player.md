title: A new game no longer fails in a place where everyone lives in group quarters
---

When a new game's draw lands on a place where every adult lives in group quarters, such as a colony, it now opens in the same state's next place instead of showing an error. Dev mode's "How this world opened" names the place that was passed over and why.
