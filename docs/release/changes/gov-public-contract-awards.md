title: Governments award public contracts to local businesses.
---

When a budget line buys work from private businesses, the government's council, board or legislature now chooses which local firm gets the work for the year, weighing each firm's bid, its size and how well the members know its owner. The firm that wins is paid from the line each month and pays its workers from it.
