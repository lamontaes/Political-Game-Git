title: The unsaved-life note no longer covers the button underneath it
---

On a phone-sized screen the note reading "This life has not been saved yet."
sat on top of the main button above the current moment, leaving it half
readable. It now sits at the foot of the screen instead, and none of these
status notes can take a tap meant for something behind them.
