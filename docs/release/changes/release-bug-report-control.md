title: Report a bug from the options screen
---

The options screen now has a Report a bug button. It shows exactly what would be handed over (the game's recent problems, the date in the game and the place) before anything is sent, and only saves the report as a file when you press Save the report. Nothing leaves your computer from the game. If the game did not end cleanly last time, the options open on the report when you next start it.
