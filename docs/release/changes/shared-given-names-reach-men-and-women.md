id: shared-given-names-reach-men-and-women
impact: patch
section: Changed
title: A man or a woman can now be called Jordan, Taylor or another shared name
---

Names both sexes carried were reserved for non-binary characters, so the game
could never produce a woman called Jordan or a man called Taylor, by any path.
The SSA's own tables say otherwise: Willie in the 1920s, Terry in the 1950s,
Jamie in the 1970s, Jordan and Taylor in the 1990s all appear on both the boys'
and the girls' top 100 of the same decade, and the research answer is that a
shared name is not reserved for non-binary people.

A stated man or woman now draws from their own list and the 36 shared names
together; a non-binary character draws from the shared names, as before. The
rule is written as data, labelled as an authored game rule rather than a
measured rate, so it can be read and changed by hand. A name is still never
read back to decide anyone's gender, and a name the player types always wins.

Every name reached is equally likely, which is the weighting the name list has
always had, so for now about one generated man or woman in five carries a
shared name. That is more than real life in most birth years. The real weights
vary by name and by year and wait on the SSA's per-name, per-year counts, which
have not been compiled yet. Saved characters keep the names they have.
