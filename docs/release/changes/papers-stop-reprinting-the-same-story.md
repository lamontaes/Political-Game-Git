title: A paper no longer reprints a story it has already run word for word.
---

Towns repeated the same few stories for years. The fishing-rights talks kept
announcing an interim arrangement, shipping kept "returning to its usual pace",
and the same road-repair proposal was adopted and withdrawn over and over,
because each recurrence was a new record. A paper now passes over a
development whose wording matches one it has already taken up. The recurrences
themselves still happen; making them vary is a separate change.
