section: Fixed
title: Dev mode now works in the installed game, not only in the developer's build.
---

Turning dev mode on in Options now opens its controls and views in the installed game: the Calendar's run and scene panels, a person's records and trace, the law and bill controls and every dev view. Before, the installed game showed the checkbox and the panels, but nothing answered them. What dev mode saves, such as a records proof or a trace report, now goes in the game's saves folder.
