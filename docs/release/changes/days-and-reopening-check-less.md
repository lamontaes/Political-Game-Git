id: days-and-reopening-check-less
impact: patch
section: Fixed
title: Days move faster and saved games open sooner
---

Pressing Day no longer re-checks the whole world after every day. The game now
checks only what that day added or changed, and still checks the whole world
when you save and when you open a saved game.

Opening a saved game is much faster in a long life. The check of each person's
remembered feelings, goals and values used to compare every record with every
other record; it now compares each record only with the same person's own.

Several everyday lookups also stopped searching every person and every place:
finding a person's housemates, colleagues, club members, home town and Congress
member now goes straight to the records that can match.
