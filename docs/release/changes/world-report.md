A development report that says what a world with nobody played did, month
by month. `npm run world:report` opens a watched world in a named place,
presses the observer clock's Day button for a number of years, and reads the
saved records back into a chronicle: races and results, bills and what each
law changed, party decisions, offices changing hands, deaths, disasters, the
press, and the lives of people near the place. Every line names the records
it came from. At the top, "What never happened" lists what a living world
should have shown and did not, with the counts that decided each item.

Five-year runs for Columbus, Ohio; Belzoni, Mississippi; and Urban Honolulu,
Hawaii are in `docs/reports/world-report/`. Nothing in play changes.
