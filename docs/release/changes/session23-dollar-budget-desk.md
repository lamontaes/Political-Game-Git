title: Executive budget requests name dollars by program family
---

Executives can send a dated dollar request from their shared office desk and compare it with the legislature's enacted program authorizations. Requests survive saving and do not create spending authority or treasury money. Current modeled budget categories remain separate from individual program allocations.

Preparing a dollar request is optional and does not impose an action deadline or block time when the player changes roles.
