section: Fixed
title: The fairness ordinance check agrees with home rule again
---

Two new rules disagreed in one check. Tennessee
and Arkansas bar their towns from passing a fairness ordinance, and states
that follow Dillon's rule now withhold powers their legislature never
granted. The check that towns elsewhere may still pass one now compares each
town with what it could do if its state already covered the grounds, so a
Dillon's rule state no longer reads as a fairness bar. Nothing in play
changes.
