title: A page left over from before an update now asks you to reload instead of showing no saved lives.
---

If a tab or a cached copy of the game from before an update is opened after the update has already run, it cannot open the saves the newer version kept. It used to show no saved lives at all. The title screen and the saved games list now say the page is an older copy, that nothing was deleted, and offer a Reload button.
