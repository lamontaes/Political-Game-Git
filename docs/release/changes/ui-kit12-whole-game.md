title: The whole game screen wears the approved look
---

Every screen of the game now uses the approved dark-glass and brass look: the title, the player card with the date and time, the menus, the conversation box with the scales, the dossier, the calendar, election night and the filing office. The old boxed buttons and tab strips are gone, and developer controls sit behind one small ring.
