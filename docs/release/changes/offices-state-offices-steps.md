`stateOffices` (a state's governor, statewide offices and legislative chambers, 194 lines) is now three named steps: `executiveOffice` for one statewide office, `chamberOffice` for one chamber, and the short function that joins them. Its answer is byte-identical for every state, with and without a place, on two dates (digest 0eb843f7…), so nothing a world writes changes.
