The rules that ask whether a scene names what is at stake, and whether a promise, refusal or threat names who, what and why, are now judged along each path through a scene, from its first line to the line in question. A "no" there is a list of gaps for the threads that write those scenes, never a line taken out of play. A words builder who adds reply lines now judges only the pairs their new lines made (`npm run words:pairs -- --since`), so the words checks stay green on their own pull request.
