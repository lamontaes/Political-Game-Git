# Feature map

One row per screen, and one per owner ruling about what the player sees (CTO, Nov 16, rule 3 of skill `done-proof`). Each row says how to reach the screen, what must show, and the check that proves it. A pull request that touches a row runs that row's check and names it in its `Verified:` stamp. The Screens lane keeps this file. Other lanes add the rows for their own screens.

The bench is `npm run bench`, and play is at `/play`. Browser checks run with `BENCH_BROWSER` pointing at Chromium and `BENCH_PORT` at the bench. Each draws its own place unless `BENCH_SEED` replays one.
