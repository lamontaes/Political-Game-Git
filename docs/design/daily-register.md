# The daily register

The register the rule `.agents/rules/cadence-and-summaries.md` asks for (owner, Nov 10: "not everything is tracked every day, and... summaries are automatic, and... if something does need to be tracked more often, then it's specifically written and it's reasoned through by the coordinator or you"). The guard `npm run guards -- daily-register` (`tests/guards/daily-register.test.ts`) fails when an engine has a daily step or a kept table that is not listed here, or when a daily step or an unfolded growing table is neither approved by name nor one of the entries main held on Nov 11 (`tests/guards/daily-register-baseline.json`, which only shrinks). How to write an entry: skill `cadence-and-summaries`.

Seeded on Nov 11 by the speed lead from one played world: South Hooksett, New Hampshire (3371220), seed s8333, main 972d0800, years 1 to 4 (184, 400, 320, 721 seconds), one process alone on a 4-core cloud container. "Not yet approved" means no one has yet reasoned why the entry must be daily or must grow: each is a speed cut to make, or a line to bring to Fable B or the CTO with its reason.
