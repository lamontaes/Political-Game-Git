## LEARN

Check process working directories and other clones when establishing exclusive
ownership; one clone's worktree list is insufficient. Preserve stopped-source
patches and hashes before file-level recovery. Keep TypeScript `.tmp` caches
local to each worktree. Exact excerpt matching proves capture consistency,
not semantic entailment. Compare generated prose reports against live measured
counts instead of maintaining magic counts in unrelated feature tests.

hosted-CI monitoring, or human/normal-route acceptance is claimed.
