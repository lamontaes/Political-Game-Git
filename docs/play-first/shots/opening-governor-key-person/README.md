# The opening's states part names the governor

`opening-montage.browser.mjs` (New Game, Advanced, New world). The sixth part of the President's address, the one to the states, now plays over the player's own state capitol, painted at night, with nobody drawn. The governor and the state's chamber leaders are named over it.
