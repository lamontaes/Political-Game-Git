# play-player-runs-only-six-offices

Bench 1440×900, seed `9d1490ac-904b-4fa8-83f2-0609986c6166` (Anguilla, Mississippi). Before (`before-travel.png`): Travel lists three filing offices, among them the Circuit clerk (county offices).
