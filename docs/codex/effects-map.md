# Effects map

The current outcome catalog contains conditions whose changes stop before reaching another condition. This map identifies the missing connections and their current owners. September 29, 2026.

## Evidence boundary

This maps every condition in place-outcome-bases-2024.json and every declared incoming/outgoing edge in links.json. A declared edge is not proof of an executed producer, researched nationwide coverage, a named-person consequence or a watched chain. Generic readers may consume keys dynamically; absence of a literal source match alone is not proof of a runtime dead end. The ten priorities below are missing outgoing catalog edges, not an invented claim that every UI consumer is absent. All three-step watched proofs remain NOT RUN and Claude-owned.

Main contains 40 conditions; the earlier 23-condition count is historical. Law values remain exact per place. Nonlaw values require broad research anchors and per-world spread; evidence gaps must not be disguised as observed facts.
