## Build (one PR each, against main, changed tests + typecheck incl. test files, proof from a random place per PR: a screenshot of the desk and the record lines)

1. **Mayor joins the shared governing offices.** `state-governing.ts`: add the municipal executive holder to `currentGoverningOffices` and `governingOfficeForPerson` (reuse `municipalExecutiveHolder`, the programOffice pattern). Done when a player mayor sees budget and agenda matters in GoverningBriefing in a random town.
2. **One bill desk for mayor, governor, President.** Route the council act (`municipal-ordinance-procedure.ts` ~:977/:1263) through `openMatter` the way `governorDesk` does, so one sign/return surface serves all three; delete the municipal-only override duplicates where the shared `overrideCount`/`executiveBillActionWindow` now serve (Replaces: lines). Done when the same GoverningBriefing shows a council ordinance, a state bill and a federal bill to their respective player executives, with the action window and override result from the shared functions.
3. **The player makes appointments.** New matter family "appointment" in `state-governing.ts`, opened by `office-continuity.ts` when a vacancy belongs to a player-held executive; options = `chooseAppointee`'s short list (~8 names from `appointmentCircle`), decision through `decideGoverningMatter`, favor recorded via `recordAppointmentFavor`; NPC holders keep the existing path. Covers mayor's manager, governor's boards, President's cabinet and justices (`supreme-court-appointments.ts` for the confirmation vote). Done when a player governor fills a real vacancy from a list of real people and the Senate/board confirmation runs through the existing vote.
4. **A real budget desk.** Extend the "budget" matter options (`state-governing.ts:638, :1842`) with amounts read from `public-budgets` (`budgetLawReading`, opening accounts): the request names dollars per program family; show it in `BudgetEconomyWorkspace` beside the matter, and compare the legislature's appropriation against it. Done when a player governor's budget request is a dollar figure per family, the appropriation differs, and both are on the desk.
5. **Vetoes, overrides and item vetoes visible.** In GoverningOfficeDesk show the action window and the override vote result (`executiveBillActionWindow`, `overrideCount`); add item veto through `applyItemVetoes` where `itemVetoPower` is not null. Done when a vetoed bill shows its override result on the desk in a state with and a state without item veto.
6. **One executive engine.** Merge the executive-work kernels and the governing matters into one inbox per office (`synchronizeExecutiveInbox` feeding governing matters, or the reverse), one list under "Your office", side by side with `office-workflow.ts` for the legislative seat. Delete the loser (Replaces: lines). Done when there is exactly one list per office and the old surface is gone.
