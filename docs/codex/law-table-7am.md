# What the law catalog reaches

The catalog has a row for every question. Existing readers are separated from demonstrated effects on people. Most questions still need research or missing behavior. A missing owner row stays visible. This table does not turn a catalog entry, a place average, or a recorded answer into a working law.

## How to read the table

Levels marked mapped are the implemented catalog mapping, not verified complete effects or legal power at every place. Held branch means the cited writer is not established on main. All-place authority and preemption remain open where the owner says so.

Repeal yes means the cited packet establishes the bounded repeal behavior; it does not certify every consequence. No — unverified means complete repeal handling has not been established, not that no reversal code exists. This distinction prevents an invented pass or an invented absence. Person-reader findings are source audits unless a worked example is explicitly stated.

Status fixed tonight refers only to the cited bounded repair. No row is marked works from aggregate output. Every owner link pins the evidence version.
