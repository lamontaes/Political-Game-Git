# 1. Why-chain

News exposed `behavioral-health-crisis-response:us-nh` because the saved
commitment event interpolated `appropriation.programKey`. That field identifies
the program and jurisdiction internally. It was printed because the producer
did not join the program's existing human label. The zero-dollar branch also
printed “commit nothing” before an alternative with the same meaning. Bedrock:
the actual capacity, linked measure or canonical program family establishes a
human subject; the internal key is not that subject.

service, numerical study, bank of state labels or guessed program is added.

# 3. Revisions

title, then an existing specific family title. Unsupported/empty/key-shaped
labels are omitted. The internal program key remains in records and tags.
Zero-dollar choices retain their alternative title in the commitment record;
the event sentence states the decision once. Nonzero choices retain their amount,
alternative title and pending-payment qualification.
