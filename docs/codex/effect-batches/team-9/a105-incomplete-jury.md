# An incomplete jury cannot decide the case

A court no longer lets an incomplete panel deliberate or return a verdict. The original case stays pending. A partial panel is not counted as a mistrial and cannot exhaust the retries into dismissal. The existing panel target remains labeled unresearched; jurisdiction-specific legal sizes and the natural panel-availability recovery caller still need their exact contracts.

## 1. Why-chain

A case can receive a verdict only after its panel deliberates. A panel can deliberate only when it meets the same target that the existing court caller uses to assemble it. Seven available people do not meet the existing twelve-person target. An empty pool also cannot deliberate. Those cases remain pending before any ballot, verdict or mistrial is saved. This chain ends at the court's existing panel requirement, which is an explicitly labeled unresearched rule rather than a researched jurisdiction-specific legal fact.

## 2. Research

This safety fix introduces no researched legal size. The existing engine already attempted to assemble twelve jurors in every trial. A105 authorizes blocking a short panel and separately requires jurisdiction-specific legal data. That data is not admitted in this branch. The existing juror selection by lot is retained; it selects actual eligible people and does not select their verdict.

## 3. Revisions

The existing target is named once and used by both assembly and the trial guard. The old zero-juror path produced a hung trial. That path could eventually count empty trials toward dismissal. The replacement returns pending before jurors are prepared or ballots recorded. A complete panel retains the existing deliberation, verdict and sentence behavior.

No polling or invented retry interval is added. The exact availability-change recovery producer remains an Audit dependency. A manual call to the existing advance function can resume the original saved case when its panel is complete; that bounded proof does not establish a natural saved trigger.

## 4. What gets built

1. Name and label the existing unresearched panel target.
2. Use that target in the existing panel assembly.
3. Return pending before ballots when the panel is short.
4. Preserve the case without writing a mistrial, dismissal or sentence.
5. Prove controlled seven-person and empty panels, canonical reload/repeat, and resumption with the complete actual-person panel.

## 5. Simulated, records, world pieces, checks

SIMULATED: complete panels retain the existing jurors' own decisions. RECORDS: the saved referral, charge and not-guilty plea remain unchanged while the panel is incomplete. WORLD PIECES: actual saved defendants, courts, seated judges and eligible jurors supply the actors. CHECKS: no verdict or juror ballot from a partial panel, no dismissal from repeated empty panels, and no replacement referral on resumption.

The test restricts the real selected panel at the existing selector boundary. It does not manufacture people, residence, eligibility or a verdict. It is controlled boundary proof, not evidence that the natural eligibility producer independently yielded seven people.
