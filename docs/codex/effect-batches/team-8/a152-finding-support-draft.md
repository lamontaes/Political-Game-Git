# A152 finding support ownership — connector draft

Before: Press reporting directly changed a candidate's support after a public adverse finding.

After: The saved institutional caller supplies a campaign adapter in the original support-first slot. Press-only calls cannot change support. This source change is prepared for Cloud Checker review, not executed proof.

## 1. Why-chain

The original code checks that the named respondent is in an actual active campaign with at least two candidates and a pending contest. The moved function forwards the saved finding event to the same canonical support writer. A recorded finding is the existing trigger; no new person's motive, score or loss is authored.

## 2. Existing mechanism and limits

The legacy magnitude remains UNRESEARCHED_FINDING_EFFECTS with the same repeat-offense rule. Extraction does not make that magnitude researched, make a finding infallible, or replace the sole decision engine. Audit has been asked to confirm the current decision-owner boundary. No new calibration or evaluator is introduced.

## 3. Production connection

advanceProceeding already saves the institutional step, event and evidence before applyFindingConsequences. It now supplies the support adapter after the existing optional restitution and referral arguments. Execution order remains support, restitution, referral, social and denial. No second metric writer or dispatch is added.

## 4. Saved records

Original campaign eligibility checks, stable keys, actual respondent, finding-event source IDs and recordSupportLoss remain unchanged. The canonical writer transfers the existing share and applies its original floor. This patch does not edit that writer. Closed proceeding replay remains authoritative; the direct adapter is not newly idempotent.

## 5. Prepared proof

Eight unexecuted cases reuse the existing six-person Kentucky filing fixture: five established seeds compare the full saved result to the original canonical writer, one press-only call leaves support records unchanged, one explicit adapter call uses the original first slot, and one actual noncandidate remains unaffected. Saved provenance, canonical reload and closed replay are asserted. This is controlled Kentucky coverage, not random-place nationwide or natural voter-decision proof.

## 6. Checks and missing links

Native tests, strict types, lint, formatting, report checker, release, zero-dice and audit:scan are NOT RUN. The existing executor has no shell; CTO authorizes connector drafts and Cloud Checker gates. Social and denial side effects still remain in press. The legacy unresearched support magnitude, actual voter decision route, natural institutional finding route and nationwide proof remain open. A152 is partial.

## 7. Worked example

A controlled saved public finding names an actually filed candidate. The adapter checks that person's existing pending campaign and forwards the event as provenance to the canonical writer. The prepared parity test compares the entire saved result with the unchanged writer using its existing source constant; no new numeric loss is supplied. This is a planned assertion, not an observed outcome.
