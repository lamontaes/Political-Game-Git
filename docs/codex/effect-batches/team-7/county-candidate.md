# County election dates and term starts have a review candidate

County offices now retain their actual county identity and use the county calendar when it has been read. New county filing is refused while district and qualification evidence is missing. The candidate also defers a recorded county winner's seating until its sourced term start. The actual county election journey remains unfinished and requires core review.

## Before

Frierson had no municipal government, so the municipal candidacy reader offered no local governing body. Reusing municipal date or qualification defaults would invent a county election date or allow filing without county district evidence.

## After

The shared identity reader appends actual Census county governments and keeps municipal identities. DeSoto uses the published adjusted 2027 dates. Loudon uses its actual 2026 county ballot and ordinary four-year August cycle. Other counties remain unknown. The existing campaign readers display a read date or an unknown date. The filing preflight refuses county qualification before generating opponents. Existing recorded campaigns are not rewritten by this preflight.

The existing local-election result handler can schedule a term-start callback in the same future queue. The callback checks actual contest, office, winner, date and calendar identity before using the existing participation writer. It preserves the incumbent before the term boundary. It uses the existing county board role.
