# Actual state members prepare Article V ratification ballots

Before: The state ratification caller pools a state's legislators and can substitute its federal delegation. It decides separately from the shared chamber vote.

After, partial: The new preparation function uses actual saved state chambers and the shared member vote. The expanded test observes unchanged ballots and reasons for 7,266 actual members in 49 states. California remains unsupported by the reused roster helper. Production ratification has not switched to this function; state approval also needs sourced chamber rules.

## Why-chain

Measured: Ratification is a state legislature's action. Congressional members cannot supply that state's missing body. The existing roster joins dated office bindings, real organizations, saved seats and active work relationships.

Measured bedrock: Each actual member decides from the same existing term-limit considerations through decideChamberVote. A player without a ballot remains absent. Missing bodies remain unsupported. Member decisions alone do not establish legal approval.
