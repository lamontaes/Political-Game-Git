# Rejected policy amendments keep their real votes

Before: A state's lawmakers could favor changing a policy, yet no amendment was saved when a preliminary vote forecast predicted defeat.

After: Their existing principle-backed cause produces a saved amendment first. Actual chamber members then decide through the common vote function. A rejected proposal keeps their names and reasons. This completes the general-policy filing slice; state ratification remains a separate unfinished caller.

## Why-chain

Measured source: the existing policy selection reads the actual lawmakers' recorded principles (`constitutional-reform.ts:702`). Previously, a private preliminary ballot and scaled chamber count could discard that cause before a proposal existed.

Removing that gate lets the existing writer save the proposal and real roll call (`constitutional-reform.ts:710`). Each ballot delegates to the common member evaluator. Bedrock: a person's saved principles inform the ballot, while the unchanged constitutional-bar consideration can outweigh a slight preference.

The existing cause does not include every possible sponsor motive, such as resident outreach or campaign commitments. This patch does not invent those records.

## Research

Binding mechanism: the CTO's October 1, 2026, 12:13 p.m. ruling (h) approves proposal-first ordering for every question kind. This is an approved simulation ordering, not a measured claim about state voting behavior.

The existing constitutional profiles supply chamber thresholds. Their source labels and supported-state admission guards are unchanged. No empirical rate or outcome level is introduced. The existing consideration weights remain disclosed authored choices.

## Revisions

Measured: the existing cause selector still picks the same majority-backed change and preserves its text, stance and terms (`constitutional-reform.ts:491`). The separate forecast and synthetic chamber scaling are deleted.

The policy ballot delegates directly to the common member evaluator (`article-v.ts:332`). The former separate production evaluator is deleted.

Missing or vacant actual state bodies remain unsupported; Congress cannot stand in for them. The test-only legacy evaluator preserves old-input parity evidence without leaving that decider in production.

## What gets built

1. Save the existing principle-backed state policy proposal before voting.
2. Use the actual saved state or congressional proposal and body in the common member-vote function.
3. Keep rejected proposals, actual member identities and recorded reasons.
4. Preserve rejection and IDs through canonical Save/Continue and repeated review.
5. Preserve terms, thresholds, cause selection, player absence and present-not-voting.
