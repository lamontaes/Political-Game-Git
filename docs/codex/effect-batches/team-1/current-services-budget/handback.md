# Current-services budget requests

MERGED: none for this candidate. Governor budget requests now have a path into the legislature, with recorded reasons when they cannot file.

Before: a governor could save a December budget decision, but the legislative intake did not turn that request into a general appropriations bill.

After: the actual February intake files the current holder's saved request through the existing bill and institution writers. It preserves the adopted first year's amounts and dates. An absent second biennial year carries the latest adopted line unchanged, labeled flat current services. A departed governor's request lapses with a saved reason.

## 1. Why-chain

The request can reach legislative action because the February governing season consumes the current holder's recorded decision. That decision identifies the actual opened budget matter and governor. The bill's first-year clauses read the government's saved adopted appropriation array because a family preference records no numeric increase. The clause dates come from that adoption and the government's fiscal-year start. If the second biennial adoption is absent, CTO's October 1, 4:51 ruling authorizes an explicitly labeled unchanged carry. Bedrock: an actual recorded request, an existing adopted amount, and the approved flat-current-services rule.

WHAT EMERGED: DECIDED means the fixture governor saved “budget:hold-flat” on December 1. HARDWIRED means the existing February intake calls the new request bridge in state-governing.ts. The filing remains a measured production-caller consequence of a controlled request; it is not a natural two-year result.

A legislative enactment authorizes the final positive clauses through the existing appropriation writer. It does not create cash or deliver a service. The office's follow-up reads an appropriation only when its sourceMeasureId matches the request's filed bill.

## 2. Research

This change consumes existing world records, not a new researched monetary estimate. AdoptedBudget.appropriations is aligned with all 18 BUDGET_PROGRAMS and stored in whole dollars. The draft converts those exact amounts to cents. Monthly spending, cash balances, category guesses and authored amount defaults supply no terms.

CTO's 4:29 ruling requires the actual saved annual or biennial cycle. CTO's 4:51 ruling permits the second year's missing adopted line to carry the latest adoption flat and requires departed requests to lapse. The first year's source dates, adoption date and opening or automatic basis remain in the clause. The original December decision date remains unchanged when the bill files in February.

## 3. Revisions

The provisional annual multiplication was removed before publication. Each fiscal year has separate availability and program clauses. Annual records accept one complete fiscal period; biennial records accept two. Missing first-year authority or cycle remains unsupported.

The consumer reuses operativeDateInWorld for an explicit saved date or sourced state rule. It rejects its game-default result. Availability starts at the later of the lawful operative date and the clause's first date; an expired period is skipped, never extended.

The initial fixture skipped pending events. The corrected fixture resolves them through the existing future-transition registry. A subsequent failure correctly identified four departing governors. The positive sample now selects actual holders whose recorded terms extend through filing; the departure is separately tested with a saved lapse event.

## 4. What gets built

1. A draft writer copies the adopted program array into append-only provisions, including explicit zero lines, with actual governor, request event, numbering session and source dates.
2. The existing season handler files that request and schedules the existing institution step. A missing decided request or source leaves a saved unfiled reason. No new member, filing quota or forced passage is created.
3. An executive-request appropriation uses the institution for initial referral and calendar action. Other bill owners and executive action windows remain unchanged.
4. The released general-budget consumer reads final provision versions and writes each positive yearly line as spending authority through recordAdoptedAppropriation. Per-year edition keys preserve repeat behavior.
5. The request follow-up joins that enacted authority through its actual measure ID.
