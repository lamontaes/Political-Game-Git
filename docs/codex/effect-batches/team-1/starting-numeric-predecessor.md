# Starting law can supply a sponsor's numeric predecessor

MERGED: none for this candidate.

Before: the automatic program compiler required an enacted predecessor with a saved measure and draft lineage.

After: a starting law can supply its own dated amount through the shared reader. The sponsor still selects an existing verified reference from recorded principles. Missing amounts and ambiguous program bindings remain unsupported. No production starting amount is added.

## 1. Why-chain

A numeric request can compile because the sponsor has recorded principles supporting the question. Those principles select an existing verified reference. The request is an expansion because the reference's amount exceeds the actual predecessor. That predecessor can now be a dated starting term because the coordinator's canonical reader identifies the law and its operative date. It needs no synthetic measure or provision. Bedrock: an actual sponsor record, an admitted current-law term and saved reference clauses.

Constituents, donors, news and independent service-window preferences remain outside this existing selection mechanism. A law without the necessary term still produces no numeric draft.
