# Governors get a session budget request before a bill can file

Before: A regular-session intake could record that the current governor had no decided budget request, then leave no linked request for that intake to complete. A lapsed matter still carried a decision event.

After: The intake opens or reuses the current governor's pending budget request. Their recorded choice files through the existing bill driver. Lapsed requests are rejected. Both adopted biennial years keep their own saved amounts.

## 1. Why-chain (five whys, to bedrock)

1. A session budget bill waits because the current governor must have a recorded request.
2. A request can be missing because the previous request expired without a choice.
3. Intake now opens the pending matter because the adopted annual lines and the government's budget cycle already provide its current-services source.
4. A later choice files because the saved intake event names that exact matter and the existing `recordDecision` writer calls the existing budget bridge.
5. The bridge requires a decided request from the actual current holder. The chain ends at that person's recorded choice and the government's adopted appropriation records.

The independent NPC path can still reach a seeded fallback without staff advice. That finding is not repaired or approved by this branch. The budget-only selection hunk and actor-record contract have been requested from the coordinator and Audit. Other governing families remain untouched.

## 2. Research

The amount source is `publicBudgetFor(world, jurisdictionId).years[].appropriations`, with the saved adoption date and fiscal window. Each whole-dollar line becomes minor units by multiplying by 100. Monthly outturn, balances and forecasts are not substituted.

The CTO's October 1 current-services rulings authorize annual one-year and biennial two-year requests. Each year uses its own adopted line. Only an absent second-year adoption carries the most recent adoption unchanged and labels the clause as flat current services. These are approved mechanism rules, not empirical rates. No new cost or score estimate was introduced.

## 3. Revisions

Existing saved dates survive. A second year with an adoption uses that year's amount, even when it differs from the first. A second year without one is explicitly unchanged. A departed governor's request lapses. A current holder's expired request cannot be treated as an affirmative decision.

The request remains pending before a real choice. This slice does not force a bill, a vote or passage. Throughput research has not supplied an actor-score mapping or units for a replacement filing threshold. That gap remains explicit; no numerical threshold changed.
