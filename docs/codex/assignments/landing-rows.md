# The landing rows: per-measure table for all 56 place measures

Owner-approved kinds (Oct 5); per-measure rows derived by Fable CTO Oct 6; any session may correct a row in its own PR with a cited reason.

Kinds: FLAG = rank residents by the records that describe their risk; the top X% change state when the place number moves X points. AMOUNT = scale the recorded amount by the change. EXPOSURE = every address accumulates the place value yearly. EVENT = rank by recorded exposure; the top share has the event through the existing writer. Nobody is notified by the landing. Ids come from data/research/outcome-web/place-outcome-bases-2024.json; 'id: confirm' marks an id not matched.
