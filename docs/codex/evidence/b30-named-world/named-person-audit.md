# Named-person source audit (Session 54, b30-p3)

Scope: generated and public-facing news, speech, and conversation name paths in
`src/simulation/press` and the presentation readers that assemble those lines.
The audit did not enumerate every prose string in the repository; it traced the
structured producers and high-risk renderers below.

| Surface                              | Name source and identity record                                                                                                                                                                                                                                       | Finding                                                                                                                                                                                                                                                 |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Press headline/event names           | `src/simulation/press/story-voice.ts` reads event participant and involved-entity IDs, then renders only IDs present in `world.people`.                                                                                                                               | No unbacked name writer found. If the event does not name exactly the counted people, the headline keeps the count.                                                                                                                                     |
| Editorial names                      | `src/simulation/press/editorial.ts` reads the person attached to continuity events, contest result IDs, or the candidacy-intent participant ID.                                                                                                                       | No unbacked name writer found. Missing records prevent the name-specific editorial line.                                                                                                                                                                |
| Story sources, responses, and byline | `src/simulation/press/desk.ts` looks up reporter, source, and subject IDs in `world.people`; source/subject dialogue is taken from their saved claim or response record. `src/simulation/press/views.ts` returns reporter person IDs alongside names.                 | No unbacked name writer found in structured attribution.                                                                                                                                                                                                |
| Election speeches                    | `src/presentation/election-speech-english.ts` reads the speaker participant and named opponent/winner moves by person ID; missing people do not supply a name fact. `src/presentation/speech-remembered-english.ts` reads the teller from `knowledge.sourcePersonId`. | No unbacked name writer found in the structured speech path.                                                                                                                                                                                            |
| Conversation dialogue                | `src/presentation/scene-conversation.ts` returns `speakerPersonId` with `speakerName` from the same saved person. Contextual and Run B dialogue resolve inserted names through `world.people[personId]` or `shortPersonName(world, personId)`.                        | No unbacked name writer found in structured dialogue.                                                                                                                                                                                                   |
| Arbitrary quoted prose               | `ClaimRecord.statement` and `HistoricalEvent.context.immediateReaction` are free-form text. Existing press stories retain the saved speaker ID, but do not carry a structured identity for any _other_ person named inside that text.                                 | Contract gap: name mentions inside arbitrary prose cannot be proven to resolve by the current data shape. No general name extractor or mention-ID record exists. CTO question #6016762995 asks whether that text-to-person mention link is in p3 scope. |

The added regression test exercises a generated-place news headline whose
person name comes from the saved event participant ID. This is evidence for the
structured news path, not proof that arbitrary quoted prose contains no
unlinked names. No person was created during this audit because no bounded
unbacked name producer was found to repair with the canonical person writer.
