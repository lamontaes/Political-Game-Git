**What.** A probe on Oct 20 (built on the recorder fix in the pool item core-stopgap-hits-miss-module-calls, PR #5452) ran `buildBenchWorld` with every module in three places drawn from all 56 (seeds `hits-h1`, `hits-h2`, `hits-h3`, purpose `hits`), two years each, and collected `core.stopgapHits`. Of the open rows in `src/core2/data/stopgaps.json`, 101 never ran; 161 did. A row that never runs in play is either a fake that no played path reaches any more (resolve it with its replacement named, or delete the code and the row together), or one that only fires in a place, law or choice these three worlds did not reach. Go through the 101, decide each by reading its marker and the code around it, and for each one either resolve it, delete it, or write the place or situation that reaches it in its `why`.

**Rules.** Never close a row by deleting only the row: the marker and the fake go with it (replace, never layer). Look before you register: read `docs/coordination/DECISION-REGISTER.md` and `docs/coordination/OWNER-DECISIONS.md` first, since some rows wait on an owner ruling. The `SG-P8-param-*` rows and other data-file rows (a parameter or a JSON table that carries a `stopgapId`) are recorded only when read through `coreAPI`'s parameter lookup, and `parameter()` caches its reads in play, so they cannot be told dead from this probe: judge each by whether any code still reads the parameter, not by the hit set. A row that only a world without a module reaches (for example `SG-GOV-staff-unpaid`, hit only with no budgets module) is a test-world case, not dead code, until those tests install the module.

**Done when.** The count of open rows that never run across at least ten places drawn from all 56 (seeds named) is smaller than 101, each row removed is resolved in `stopgaps.json` with a resolution that names the code that replaced or removed it, and the tripwire tests pass. The PR body lists the rows closed and the rows kept with the reason.

**Files.** src/core2/data/stopgaps.json, src/core2/stopgaps.ts, and the files the rows name
