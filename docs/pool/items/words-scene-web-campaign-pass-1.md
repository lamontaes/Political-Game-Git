**What.** The first pass of the campaign domain of the scene web. It covers two of the owner's missing scenes, the debate and the primary challenge. Each gets a packet from real lives. Where nothing stages the scene, the gap is filed for the director, or added as evidence to the item that already holds it.

**Rules.** Serves `scenes-from-life`: a packet per episode, no real name or line ships. Ask why: each gap names the record that exists and the code that never reads it. One rule, all 56 places: the report is regenerated from a drawn place with its seed named.

**Done when.** Two packets in `docs/design/scenes/from-life/` name their nearest types, and `npm run scene-web` (buildBenchWorld, drawn place and seed named) links them. The debate's gaps are added to `words-debate-opponent-scene` and `words-debate-answers-not-campaign-stops`. The primary challenge is filed as `scene-challenged-from-within` (lead director). `english-parts-banks` passes.

**Time box.** 2 hours.

**You will see.** In the morning report, the campaign rows with real lives behind them; in play, once the director items land, a debate and a call about a challenger from your own party.
