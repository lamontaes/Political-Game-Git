**What.** The game keeps what other states do, and the player has no way to look. The audit's words: "No screen opens another state, its governor, its legislature or its vote." What a player gets is a Nation heading in the News with one-line items such as "Bottle deposit in New York became law." The roll call for another state's vote is built correctly when asked for (`rollCallOf` in `src/core2/modules/world-legislating.ts`), and nothing in the game asks: only its own test does (`src/core2/state-sessions.test.ts`, near line 82). That was read in the code and confirmed by the audit's reviewer. In the played year in Caño Martín Peña, Puerto Rico (seed 50fe2d1143af), 54 other states and territories changed 473 laws that no screen could open. Build one States screen from the records already kept, for all 56 places: pick any state or territory and see its governor, the party in each chamber, its laws in force, what it changed and when with the vote count, and open any change to its roll call and sponsor. It is a view only: it computes and stores no fact of its own.

**Time box.** 8 hours for one Sonnet session. When it runs out, push what passes, set the state honestly with a one-line note, and stop.

**Rules.** No hand-written player text: every label is a control name and every sentence comes from the English engine's banks; the screen shows no record kind, id, ISO date or unrounded number. Replace, never layer: the screen is drawn with the one list-beside-detail renderer and the shared controls, and any older state list it replaces is deleted in the same change. One rule, all 56 places: every state, D.C. and each territory opens the same way from its own rows. This is a game, not a spreadsheet: the page tells what a state did in sentences a player can use, not a table of every law row. Owner, November 5: "generate on demand", so opening a roll call builds it then, the same every time and agreeing with the count, and it is kept once seen. Owner, November 8: "Most of this stuff should not be new coding. It should just be reading the code and then just displaying it in different ways." Owner, November 8: "No arrows and no '1 of N' pages anywhere."

**Done when.** A second session, not the builder, runs this in the running game. Start the bench (`npm run bench`, play at `/play`) with the Place field empty so the place is a drawn place, and write down the place and seed. With dev mode's Run on the Calendar, play one year. Open the States screen, pick a state other than the player's own, and see its governor by name and party, each chamber's party count, and a list of what it changed in the year with dates and vote counts. Open one change: the roll call lists members voting yes and no, the two lists add up to the count on the row, and the sponsor is named. Close it and open it again: the same names. Click a Nation item in the News: it opens the same change on this screen. Take a screenshot of each step at 1440 by 900 with the place and seed under it. Then the named repro, Caño Martín Peña, Puerto Rico, seed 50fe2d1143af, one year: any of the 54 other states and territories opens, and its changes are listed. The screen follows the approved mocks and passes the no-scroll and no-Continue-or-Back browser checks. A browser test opens two states in a drawn place and fails if a roll call does not add up to its count. The owner plays it: he reads that a state passed a bottle deposit, clicks it, and sees who voted for it and who signed it.

**Notes.** From the Fable audit, Pillar 3; the audit names it one of two medium pieces worth doing before the country tier: "add one States screen that opens any state's laws, governor and roll calls from the records already kept." One point where the code on main differs from the audit's wording: the Politics screen already has a state filter that lists every sitting member of any state's legislature (`stateLegislators`, tested in `src/bench/government-states.test.ts`), and election night's Nation page lists other states' governor races (`src/bench/nation-governors.test.ts`). So a player can list another state's members; nothing opens that state's laws, its governor outside election night, what it changed or a roll call, and `rollCallOf` still has no caller but its test (confirmed Nov 10 by search). Build this screen onto that filter, not beside it. The audit did not test what the Nation items in the News do when clicked. It reaches further once `nation-other-states-never-change-an-amount` and `gov-other-towns-and-counties-never-meet` land, and it does not wait for them.
