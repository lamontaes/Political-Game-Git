The owner, Nov 12: "go with A plus the years table. do a mock for all the different metrics that will be tracked. use a real game and look at the history and make the metrics from that. i assume the history wont show because it never has."

Layout A (picked): areas down the left (Jobs and pay, Prices and money, Homes, Schools, Health, Safety, Roads, The town's books, People, or whatever the records support), Town / State / Country top right, four headline figures with last year under each, a short report saying what moved and why (causes link to records), and inside each area a table of the years side by side with this year lit. Clicking a measure opens its timeline: one line over the years with each value written on it. Reference: https://claude.ai/artifact/A1mSQGEnHHAfs3LJ2yYz8r

You do research only: change no game code, open no PR to main. Read AGENTS.md first. Work in this cloud checkout: `git fetch --unshallow origin`; set OCD_STORAGE_OVERRIDE="cloud session, owner approved Oct 14" on every npm command; run npm install once, never npm ci. Post `Metrics researcher <name>: online` on issue #7365 after `npm run pool -- check-in --as "<your model and tool>"`.

1. **Inventory.** Read src/bench/metrics.ts, src/core2/modules/world-panels.ts, the macro and regional engines (src/core2/macro-model.ts, src/core2/regional-model.ts, src/core2/modules/regional.ts), the budget view (src/bench/budget.ts), and every module whose records a player would call "how my place is doing": jobs and pay, prices, homes and rents, evictions, schools, health, crime and police, roads, the town's, county's and state's books, population, births, deaths and moves, help programs (unemployment, food, housing). For each measure write: its plain name, the level(s) it exists at (town, county, state, country), the record it comes from (module, table, field), its unit, and whether the world keeps it over the years (which months or years, how far back, e.g. "the regional engine keeps the last twelve months and each December"). Note which measures have a value for each year, which have only this year, and which have none.
