# Merger log

A merger that cannot comment on the crew's issue writes its lines here, on the branch `merger/log`, and pushes after every line (`docs/pool/START-A-MERGER.md`, "Talking to the CTO"). The CTO reads that branch. On main this file stays empty below this line.

Each line: the UTC time, then the line as it would have been posted, starting `Merger <name>:`.
