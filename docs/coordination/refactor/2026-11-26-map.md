# The refactoring map (Nov 26, 2026; updated 1:55 a.m. to cover every engine)

**Limit:** this pass read file names, sizes and the description at the top of each file it suspected, plus the repo's own check lists. A duplicate inside one file, or under names that don't look alike, is only found by reading every file, which needs a checkout. How deep each engine was looked at is in the per-engine table.

**What this is:** every place found where the game does one job in more than one place, or where code goes around the one place that should do it. It also says what's already been combined, and what is new work rather than slimming down.

**Owner, Nov 25:** "THE JOURNAL, DIRECTOR, PERSON CARDS, ETC ALL PULL FROM THE SAME HISTORY. STOP MAKING NEW SYSTEMS FOR NEW THINGS WHEN THEY ALL USE THE SAME THING."

**Owner, Nov 26:** "What are other things like that, where there's a bunch of different files that are doing maybe a bunch of different things in a bunch of different places that can and should be combined or and slimmed down and deleted?"

## Where the numbers come from

- **The commit:** every number comes from story/first-evening at commit `0ccee9d4` (Nov 25, 11:05 p.m. EST), still the branch head at 1:44 a.m. Nov 26.
- **Branch:** the one history reader is on this branch, not on main. Story PR #10390 merges cleanly with main but is a draft, blocked by its checks.
- **Read-only:** nothing was changed.
- **How each number was measured** is given in brackets. "Not counted" means it needs a full-text read of the branch, which wasn't done tonight (see the last section).
- **"Check" means a test that fails the build** if the count goes up. Most of these lists may only shrink.

**Kinds of row:**
- **Duplicate:** two pieces of code do the same job. Merge them into one and delete the other.
- **Bypass:** the one place already exists, and callers go around it.
- **Gap:** something missing. That's new work, not slimming, so gaps are listed separately.

No row asks for a line, bank or scene to be edited or deleted. Where a check's list is made of lines, it's reported as a count with its engine cause.

## Gaps (new work, not slimming)

- **"What mattered."** The reader hands over every event, with no measure of how much each one led to or how many people it touched. The Journal's moments have impact, hindsight and echo fields set to zero (row 4). Speeches have their own picker for the world's conditions (row 3). Nothing else has one.
- **The cause links go unused.** Every event comes with what caused it and what it led to, and no word-writing code uses them. Measured three ways:
  - the history work's changed lines;
  - a direct check of journal.ts, loading.ts, outline-planner.ts, speech-outline.ts, conversation.ts, scene-talk.ts, purpose-scene.ts, printed-words.ts, nation-news.ts and english-newscast.ts;
  - code search on main, which finds them only in the campaign engine's own records.
- **News uses only a little history.** The stories the press printed are worded from their own record by `src/bench/printed-words.ts`, which asks the reader exactly three things: who held a seat before, an official's earlier exposed votes, and where someone who died was born. It asks for nothing wider, such as what led up to the event or the last time it happened. The paper's Nation heading reads the reader for laws other states passed (`src/bench/nation-news.ts`). [read: the 3 `historyOf` calls in printed-words.ts]
- **Monthly numbers aren't events.** Money, prices, jobs and health rates are kept as monthly series (world metrics, the outcome web's months, the economy's months), not as things that happened.
- **Kept only by their own engine:** races held, press interviews, earlier budgets (`src/bench/history-reader-proof.test.ts`, ENGINE_ONLY).
- **Not records yet:** appointed terms, a law being replaced, a chamber's changes.
- **Open stand-ins:** 194 in the core's register (50 partial models, 30 missing mechanics, 25 missing records, 18 faked mechanics, 13 missing engines and others) and 28 in the director's.
