## What the core is (the CTO's definition)

The foundation every engine plugs into, holding nothing about any one subject:
1. the kernel (ids, dates, draws, fixed-point money, hashing);
2. one game state with an owner for every part;
3. one record of what happened (the write path, the event bus, the reader);
4. the clock (the day loop and advancing);
5. the plug (`CoreModule` and `registerModule`);
6. parameters and data;
7. starting, saving and loading a world;
8. the choice engine.

## Verdict

The design is sound. The dependencies run the wrong way: the core imports the engines, which is where the import cycles come from.
