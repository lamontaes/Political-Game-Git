## How merging worked today

- **Snapshot a pillar branch** with `gh api git/refs` (create `cto/<x>-merge-<hhmm>` at the branch head), then merge main in via `POST repos/.../merges`. A 409 means conflict, so send a fixer. Then `gh pr create`.
- **Merge when** `repository`, `unit` and `golden-path` pass. Unit may be SKIPPED when no tests changed. Main has no branch protection.
- **Release notes:** `release:check` needs `docs/release/changes/<id>.md` (frontmatter `id`, `impact`: none/patch/minor, `section`: Added/Improved/Fixed/Changed, `title`) whenever game files change. Clean snapshots often lack one; add it before merging.
- **The American-English guard** flags words like "Ward". Surname lists need an `ALLOWED_FILES` entry in `tests/american-english.test.ts`.
- **Random-town tests flake.** Re-run once; if a real bug shows, send a fixer with the seed.
- **Routines:** creating one attaches every connector. Always follow with `update {"clear_mcp_connections": true}`. If `run_once_at` is already past, it never fires; set a future time.
- **After every merge round,** check the played world: the new test once merged, or re-run SIM-CHECK `trig_019Vrt6BEHaxj934xZp5KxH1` with fresh seeds.
