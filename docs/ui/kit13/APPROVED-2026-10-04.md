# Kit 13 — approved controls (owner, Oct 4, 2026)

The sheet `approved-controls-2026-10-04.*` is the owner's approved control set for Kit 13. Every menu mockup and build uses these exactly:

- Actions: Continue (primary, brass corner mark only while activated) and Back (plain), two sizes. Clean edges, fine-grain texture, not mono.
- Progress bar: brass frame, dark-to-light gold fill.
- Slider: brass handle; rest / hover / dragging states.
- Icons: Pin, Calendar, People, Money, Search, Return to character (gold line icons).
- Checkboxes: gold outline; checked = gold check.
- Tabs: People / Calendar / Money; selected tab = raised glass box.
- Search: rest = icon + text, unframed; hover = thin box fades in; clicked = solid box with caret.
- Dropdown: rest = plain text, no chevron; hover = thin box; open = plain list items without chevrons.
- Close = thin X; Back = return arrow; both light.
- Typography: Cinzel (titles), Fira Sans (controls), Andada Pro (narrative).
- Corners: brass corner ornaments on the panel; no binding, no circle-for-the-day, no thin gold rules above/below sections, no HTML/CSS box stacks, no scrolling inside a menu.

## Chevrons

A chevron appears ONLY on a static button while it is activated (pressed or selected). The radial menu has no static buttons, so it never shows chevrons, at rest or open. No chevrons on menu items, cards, tabs or list rows. Owner rule, stated repeatedly; final Oct 5, 2026.

Owner's words (Codex session, Oct 4): "i like the stuff on the corners", "I don't like the binding", "remove the chevron from the dropdown", "brass handle", "Lighter the x and return arrow are both fine", "the bottom left needs the UI. EVERYTHING. game wide unity".

## Permanent chevron rule (owner, October 5, 2026)

A chevron appears **only on a static button while it is activated**. It is absent at rest and on hover. Radial menus have no static buttons and show **no chevrons**, at rest or open, including while an item is pressed or selected. This rule governs button corner marks as well as text chevrons; panel corner ornaments remain part of the approved panel frame.
