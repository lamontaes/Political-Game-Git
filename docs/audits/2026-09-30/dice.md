## 2. `src/simulation/decisions.ts` — the "close-choices" mechanism and every call site

### How a decision is scored

`decisions.ts:162-168` — each option's base score is the sum of its considerations, `considerationScore = IMPORTANCE_WEIGHT[importance] * CONFIDENCE_WEIGHT[confidence]`, negated when `direction !== "supports"` (`:373-378`; weights `slight 1 / moderate 2 / strong 4 / decisive 6` × `low 1 / medium 2 / high 3`).

### What the RNG decides

```
decisions.ts:56   const CLOSE_CHOICE_WINDOW = 2;
decisions.ts:176  if (context.randomness === "close-choices" && available.length > 1) {
decisions.ts:180-183   const closeOptions = available.filter(option => highest - baseScore <= CLOSE_CHOICE_WINDOW);
decisions.ts:184-189   for (const option of closeOptions.length > 1 ? closeOptions : []) {
                         const optionRng = new SeededRng(world.seed).fork(`decision-v1:${decisionId}:${actorPersonId}`).fork(`option:${option.key}`);
                         randomByOption.set(option.key, optionRng.integer(-1, 2));   // -1, 0 or +1
```

When two or more available options sit within 2 points of the leader, EACH close option gets an independent −1/0/+1 nudge (`:188`), then the final rank is `baseScore + random` (`:192-198`). Because the nudge is per option and up to ±1 each, a 2-point favourite can lose (favourite −1, runner-up +1 → tie → alphabetical). So the roll can flip a decision the person's own considerations had already decided by up to 2 points, not only exact ties.

### The existing tie-break after the roll

```
decisions.ts:199-203  .sort((left, right) => right.score - left.score || left.option.key.localeCompare(right.option.key));
```

The only deterministic tie-break is **alphabetical by option key**. There is NO records-based tie-break: nothing consults the actor's `personalityTendencies`, `personalValues`, `goalStates`, `privateBeliefs`, `principles`, `memories`, or prior `decisionTraces` — even though the evaluator already snapshots exactly those records as sources (`decisions.ts:414-592`, `snapshotSource`). Replacement: on a close call, re-rank close options by (a) the actor's most recent durable `decisionTrace` on the same `decisionType`/subject (consistency), then (b) the count of `supports` considerations backed by `person-fact`/`life-history` source refs vs. `perception`-only refs, then (c) `personalValues.salience` of the values cited; if still level, return `outcomeKind: "undecided"` (a new value — today only `"selected" | "no-available-option"`, `:239`) and let the caller defer. The roll's `rngVersion: "decision-rng-v1"` (`:244`) and `randomContribution` (`:219`) fields would become always-`"none"`.
