## Coming Soon

- Page may go up well before release; first releases need a public Coming Soon page **at least two weeks** before release.
- Typical store-presence review **3–5 business days**; submit **at least 7 business days** before desired visibility.
- After approval, owner still clicks **Post as Coming Soon**.
- A finished saleable game is not required to **prepare** the page. A near-final **build** is required later for product-build review, not for this packet.
- Steam Direct: $100 app fee; **30-day wait before first release** after paying the fee — this is not a ban on preparing copy.

## Store-presence review (what Valve checks)

- Features and shots must be available at launch, or planned items must be clearly not-yet-released.
- Capsules need a readable title/logo.
- Screenshots = gameplay only.
- Description detailed and coherent; **no links to other websites** in that section.

This packet’s long description labels planned scope and forbids 50-state / unlimited-mod / finished-pose claims.

## Product-build review (later; not this packet)

- Game starts on every OS ticked on the page.
- Ticked Steam features must exist.
- Steam Wallet required for in-game purchases (none planned).
