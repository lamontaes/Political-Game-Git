## Concrete resolver for Lane 5 review

Lane 2's branch lane-2/sibling-names now provides the pure function distinctSiblingGivenName(seed, key, person, takenGivenNames) in src/core2/sibling-names.ts. It preserves a noncolliding name; otherwise it selects an unused name from the existing gender corpus and birth-cohort functions, comparing case-insensitively. It returns only a first name and writes no records. The proposed identity-writer call walks the existing living siblings, starts the taken list with the player's chosen first name, and stores each returned name on the sibling, adding it to the list before the next sibling. Keep surname, identity and all relation IDs. The card's historyLines already reads family:child's otherPersonId through the current person's record (src/bench/card.ts), so no screen-side name logic is required.

Requested shared scope: Lane 5 accepts Lane 2 adding the import and resolver call inside chooseIdentityV1, or Lane 5 makes that call itself. No acceptance is claimed here. Everything else in state.ts remains Lane 5's.
