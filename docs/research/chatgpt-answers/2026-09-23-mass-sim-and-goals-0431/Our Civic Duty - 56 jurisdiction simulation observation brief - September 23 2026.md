# What to capture in the 56-jurisdiction simulation

Claude's run across all 50 states, D.C., and the five inhabited territories is already under way with different people. Keep it running. The key question for this run is whether a situation and its dialogue arise from each saved person's circumstances, or whether the game selects the same prewritten incident with changed names. Record what the run can show now; mark unavailable evidence as unmeasured. A scene count, a saved event, and a changed place name do not by themselves demonstrate modular life play.

## Before, or as soon as the run can report it

Record the exact game head/build, simulation version, one seed per save, the jurisdiction and starting place ID, and the controlled person's stable ID and age for each of the 56 saves. Record whether any input place defaulted to Kentucky or Lexington instead of the requested jurisdiction. Confirm that D.C. and American Samoa, Guam, the Northern Mariana Islands, Puerto Rico, and the U.S. Virgin Islands are distinct playable inputs. This is a coverage check, not a claim that every local law or municipality is modeled. The owner requested the 56-place sweep in this conversation and previously rejected Kentucky/Lexington as a universal test default.

## During the run: one compact row per life

For each jurisdiction, record the first meaningful scene or conversation the person encounters and the first later return, if either occurs. The row should identify who initiated it; what recorded circumstance gave them a reason; when and where it happened; what the controlled person and other participants could know; the offered action; the other person's actual response; the time spent; and the resulting Journal line. If no meaningful event occurs during an interval, record a quiet interval rather than forcing a moment.

Flag these cases for exact transcript and event provenance:

1. **A premise appears at selection.** The [opening-life selector at `3c41de9c`](https://github.com/lamontaes/Political-Game-Git/blob/3c41de9c1d2c48cd35d1f4a3c8b14c5f2fe5b060/src/presentation/life-scene-flow.ts#L289-L387) chooses an authored beat and then records its prose as an event. The [growing-up selector](https://github.com/lamontaes/Political-Game-Git/blob/3c41de9c1d2c48cd35d1f4a3c8b14c5f2fe5b060/src/presentation/formative-play.ts#L143-L231) presents catalog prose after selecting a situation. For each flagged case, say whether the claimed incident was independently established before the scene was offered.
2. **A producer records a fixed request.** The [adult opportunity writer at `3c41de9c`](https://github.com/lamontaes/Political-Game-Git/blob/3c41de9c1d2c48cd35d1f4a3c8b14c5f2fe5b060/src/simulation/life-opportunities.ts#L831-L905) can generate a Saturday invitation or the same family-picnic proofreading request. A saved request is necessary, but test whether its terms follow the initiator's actual life instead of a fixed instance.
3. **A choice becomes an unearned outcome.** Compare the selected action, any response, and the later Journal sentence. The [export's growing-up situations](https://docs.google.com/document/d/1CYxCB7AUjkUcGSrLhn77EZ8sG3DpctIgfnMQ3CqmdQg/edit) include attempts remembered as having succeeded. Flag outcomes that lack an intervening world event or other person's decision.
4. **Routine activity interrupts play.** Flag automatic 15-minute reading, resting, drawing, or sketching moments and visible “No time passes” labels. The owner decided in this conversation that routine activities are optional and instant choices have no time label. Skipping routine meetings or activity detail must not create a penalty merely because the player let the simulation proceed.
5. **A place changes only the name.** Compare similar situations across at least three contrasting saves, including one inhabited territory or D.C. Note differences in people, needs, schedules, knowledge, local institutions, and available choices. Do not call a title or place-name substitution jurisdiction-specific behavior. Do not assume a territory uses a state's office or election rules.
6. **A goal meets a real opportunity.** The owner chose this as the first [modular conversation proof](https://drive.google.com/file/d/1WvsOTq3dwueqx_jceeaT524S0dwr_41F/view). If a saved person has a recorded aim and a relevant opening actually arises, capture the aim record, opening or request record, initiator's reason and knowledge, eligibility and timing, both people's choices, and the resulting state. If the person has an aim but no opening, check that no offer is conjured. Mark this **not observed** only if the run can inspect aims and openings and finds no qualifying pair; mark it **unmeasured** if those records or the dialogue path cannot be checked. Do not restart or force one into the 56 saves merely to fill the row.

## After the run

Keep a 56-row coverage table with each save's jurisdiction, place, seed, controlled person, first meaningful scene, first flagged issue, Save/Continue result, and an **observed / not observed / unmeasured** status for each watch item. Attach exact screen text and event links for failures and at least three contrasting deep traces; summarize routine clean rows. Replay one chosen save at the same seed and head to check reproducibility, and compare a second seed in the same jurisdiction to see whether meaningful circumstances change rather than names alone. If a run cannot expose event provenance or a later return, say so. Do not count source inventory, fixture tests, or a `PLAYER_REACHABLE` label as ordinary-play acceptance.
