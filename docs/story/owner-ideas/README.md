# The owner's own ideas

The owner's ideas for scenes, speeches, news and the told life, written down as he gave them, so a writer can turn each into an element (`docs/story/elements/`) the way a real moment is: the general pattern, never a script. His spoken notes are in `docs/coordination/voice-notes/`; one file here per idea, named for it, with the date and his words.

Skills `scenes-from-life` and `story-writer` read this folder before writing a line no element matches.
