# Legislation mocks (conditionally approved by the owner, Nov 8, 2026)

The owner, Nov 8 about 1:35 a.m.: "I'm going to conditionally approve all the UI stuff you made earlier, the game screens, and I want you to just go ahead and do that for everything else that's needed." These seven screens follow one town bill from writing to the executive's desk, then a state bill being followed from home. Build them at every level (town council, county board, state legislature, Congress) with the shared look in `docs/mocks/2026-11-07-approved/MENU-LOOK.md`.
