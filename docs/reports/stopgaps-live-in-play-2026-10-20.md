# Open stopgaps live in a played world, Oct 20, 2026

In one played town, 126 of the 269 open stopgaps were live: the game used them over two years of play. The list below shows which, so the next session can replace the ones the game leans on most.

## What was run

One town, George Mason, Virginia (drawn from seed `hits-probe-1`), opened with every module and played 700 days from the game start. At the end I read which stopgaps the run had touched. Every one touched was an open row.

A stopgap not on the list may still be live in another town, under a law enacted later or in an election cycle this window did not cross. This is evidence for the order to work in, not a reason to close a row.
