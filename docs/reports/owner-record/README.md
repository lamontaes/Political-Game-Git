# The owner record

What lamontae has actually decided, in his own words, from every source we
have. Built 2026-09-22 because a coordinator that replaces the current one
starts cold, and because the answer to most questions a lane wants to ask him
is already in a sentence he wrote.

**Read `01-decisions-governing-current-work.md` first.** It carries the
decisions that change what a lane does tonight, with the later statement marked
wherever two conflict. Files 02 to 05 are the complete verbatim record behind
it, and `06-routing-list.md` is the same material sorted by which lane owns it.

## The rule this exists to enforce

He does not repeat himself, and he minds being asked twice. On 2026-09-22 he
told this thread, of two questions it had put to him: _"This should be given to
chat GPT... you should have gotten that from the main chat."_

So before putting a question to him: search these files. If the answer is here,
it is answered. If it is a judgement about how the simulated world should feel
rather than a fact about our code or a decision only he can make, it goes to
ChatGPT as a research brief and ChatGPT comes back to him.

## How to cite from it

Name the file and the message index: _overnight [81]_, _merge263 [2]_,
_modgen [148]_. A quote without its index cannot be checked, and several
statements in here were later superseded by him — a quote that does not carry
its date can be the wrong half of a pair.

## What this is not

Not a task list, and not authority. It is evidence of what he decided, at the
date he decided it. Where he has changed his mind, both statements are here
with the later one marked; do not quietly keep the newer one and drop the
older, because the older usually explains what he was reaching for.

Nothing here overrides the Game Constitution, the Decision Register or an
explicit later message in the project chat.
