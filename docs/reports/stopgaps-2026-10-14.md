## Questions for you

1. **What date does the game start?** Several rows exist only because the opening world is January 2021 while the data is newer: the Census and wage figures are from later years, and the laws and officeholders of 2021 were never rebuilt (SG-P8-opening-vintage, SG-P8-historical-start). Recommendation: open the world on the date of the newest data, say so on the screen, and delete the 2021 rebuild. Answer yes or name a date.
2. **May a number that has no real-world measure be marked as a tuned setting and stop being a stand-in?** 42 rows are weights and speeds such as how much stress fades per day or how much a trait counts in a choice. No survey measures them. Recommendation: yes. Each gets the TUNABLE tag in the parameter table with the spread we check it against, and the row closes. This is the only way those rows can close, so I counted them under Estimate until you answer.
3. **When a state's law settles an exact tie by drawing lots, should the game draw the lot or hold a second election?** About 34 states use a lot in general elections. Recommendation: draw the lot as the law says, show it as a scene, and record it (SG-GOV-tie-by-lot). The owner-ruled no-dice rule forbids rolling for actors; a statutory lot is the law's own procedure, so your call.
4. **May the opening use Freddie Mac's weekly mortgage rate?** The CTO excluded it earlier, so mortgage rates after April 2019 are a Treasury yield plus an old average gap (SG-WORLD-macro-mortgage-spread). Recommendation: yes. It is the standard public series and removes the guess.
5. **Do we ship without painted rooms for a president or governor at home, and without a different painted look for each activity?** Today a president at home stands outside the White House, and a teen's one look is used for every scene (SG-LOC-residence-rooms, SG-PEOPLE-one-look-per-activity). Recommendation: yes for early access, since neither changes a rule; the art requests stay on the list.
6. **Do laws change a budget line or a metric, and not each person's record?** 14 rows in the law-reach group (Medicaid coverage per person, vouchers per child, cannabis sales, set-aside units, cash bail, redistricting and others) record a right on people but nothing reads it. The Political Process moves a metric or a budget line for the same law. Recommendation: yes, delete the per-person mechanic and the row. Where the core already has the call (leave pay, rent aid, assistance, union dues, repricing a contract), I marked it Fix instead.

## Method

I loaded both registries, read every non-resolved row, grepped each id in the code, and sorted rows by reading the stated fake, the reason, and the replacement. I checked the status notes in the core file for which calls the core answered, and confirmed in code that fillInPerson, socialSecurityAges, stancesOf, registerPropertyTax, registerBoardAppointer, registerUnemploymentTerms, closeBusinessByChoice and the place-prices module exist. I did not run the game or the tests. Proposed values and spreads for the Estimate rows are not looked up. For what The Political Process needs, I used the baseline map in the roadmap folder, because its own files are unreadable; where it is silent I recommended deleting and the Delete list can be reversed row by row. Fix rows beyond the ten were judged from the replacement text, not by trying the switch, so some may turn out to need a core change. Every row got a bucket; none went unclassified.
