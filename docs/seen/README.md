## Method

Three places the game drew, replayed with one script on three benches. Before is main at `64988a4b`, played early on Nov 11. After is main at `007dfd93`, played at 12:38 UTC. Of the 30 scene slots, 20 read differently, 2 read the same and 8 were not reached in one run or both. Each before run played about 14 minutes; each after run played 12.
