# Kit 13 UI graphics

Graphics for the screens in the Oct 14 screen plan, painted in the Kit 13 look: smoky dark glass, hairline brass-gold corner brackets and pale gold line work. Every file is a PNG with a transparent background. None carries words; the screens write their own text.

Made in Firefly (Nano Banana 2) on Oct 14, 2026, using a Kit 13 dialogue card as the style reference. The look follows historical strategy games (Crusader Kings, Suzerain, Victoria) and The Political Process's menus. The Firefly prompts are in `cto/custom-model-training-oct13:training/kit13/ui-jobs.js` and `ui-jobs2.js`.
