# PG Visual Review Workflow

1. verify dev-server identity first;
2. verify exact branch/SHA being reviewed;
3. open/use fresh browser state;
4. inspect representative responsive viewports;
5. actually pointer-click visible semantic objects;
6. actually keyboard-activate them;
7. inspect:
   - physical seating/contact;
   - foreground/background occlusion;
   - visual sharpness;
   - floating-HUD/pasted-overlay residue;
   - safe areas;
   - responsive resizing;
   - hitbox alignment;
8. report PASS/FAIL issue-by-issue.

Explicit rule:
AUTOMATED TEST SUCCESS MUST NOT OVERRIDE A HUMAN-VISIBLE FAIL.
